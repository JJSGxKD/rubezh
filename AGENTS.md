# Для ИИ-исполнителей

Правила репозитория — [`CLAUDE.md`](CLAUDE.md), они обязательны для любого агента:
Claude, Codex, Gemini и других.

Работа берётся только из реестра задач — [`tasks/README.md`](tasks/README.md):

1. Выбрать задачу своей модели и уровня: `pnpm task next --executor <модель> --effort <уровень>` (`--runner local` — если есть Docker, `--runner owner` — на машине владельца).
   PR на доработке — первыми.
2. Захватить её веткой `task/T-NNNN` (`pnpm task claim`) или продолжить PR на
   доработке (`pnpm task resume`).
3. Сначала тесты, потом код — только в зонах задачи.
4. Закрыть задачу: `status: done` — файл остаётся в `tasks/`, в архив его
   перенесёт уборка тимлида. Гейт и PR в `dev` (первая строка описания —
   `Задача: tasks/T-NNNN-….md`): номер PR — в заголовок сводки сразу после
   открытия, трейлеры коммита — после пустой строки; перед подписью — строки
   `Поток:` и `Запустил:`. На PR — метка статуса «на ревью», в том числе
   на черновике с вопросами (без неё задача висит «в работе»; после
   доработки снять «в работе»). Ответа не ждать — сразу следующая задача.

PR вливают тимлиды, исполнитель — никогда. У каждого PR задачи ровно одна
метка статуса: «в работе», «на ревью», «доработка» или «ждёт владельца»
(`tasks/README.md`, «Метки статуса»).

Задачу берёт только тот исполнитель, чья модель указана в поле `executor`, и
с уровнем `effort` из того же файла. Так решили тимлиды, отклоняться нельзя.
Поток в `--owner` — `аккаунт / модель / уровень`: `claude-3 / sonnet-5.5 / medium`.
Как работает поток без остановки — `tasks/README.md`, «Автопоток». Какие потоки запускать сейчас — `pnpm task streams`.

Коротко, что нельзя:
- пушить в `dev` и `main`;
- вливать PR;
- трогать чужие ветки `task/*` — кроме PR с меткой «доработка», взятого
  командой `pnpm task resume`;
- пушить с `--force`;
- выходить за зоны задачи;
- копировать корневой `.env` с настоящими ключами;
- запускать бота с боевым токеном;
- делать `prisma migrate reset` и `docker compose down -v`;
- менять настройки репозитория и секреты.

Если в задаче что-то неясно — не додумывать: черновик PR с разделом
`## Вопросы`, независимые шаги — до конца, потом следующая задача. Ответ
придёт меткой «доработка», и закончит PR любой поток той же модели и уровня.
