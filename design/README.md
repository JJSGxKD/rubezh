# Дизайн

Здесь лежат решения по облику игры и макеты, по которым пишутся задачи
`tasks/`. Источник правды для **значений** — токены:
- `packages/design-tokens/src/tokens.css` и `src/index.ts` — палитра,
  гарнитуры, шкалы, радиусы, срез;
- `packages/app-shell/src/design-system/tokens.css` — поверхности, кнопки,
  анимации игры.

Здесь — **правила и образ**: почему так и где что применять. Макеты — HTML на
тех же значениях: открываются в браузере, исполнитель видит то же, что
тимлиды.

## Направление: «Сумеречный рубеж»

Утверждено пользователем 06.10.2026, после трёх кругов
(`directions/directions-2026-10*.html`).

**Сеттинг** — славянский фольклор и городские легенды (`docs/05-game-design.md`
§2). Рубеж — граница между миром живых и Навью. Сумерки, а не ночь: тёплый
свет очага и бирюза оберегов против надвигающейся тьмы.

| Что | Решение |
|---|---|
| Палитра | Фиолетово-синие сумерки (`bg #1d1c31`, `surface #28273f`), оранжевый жар очага (`accent #ff8f3f`), бирюза оберегов (`secondary #46d9c6`), тёплый светлый текст (`#f3eee6`). Полная таблица — T-0012 |
| Шрифты | **Russo One** — заголовки, кнопки, крупные цифры. **IBM Plex Sans** — текст. Только кириллица и латиница, файлы в бандле |
| Грани | Строгие. Скругления 4 / 6 / 8 / 10 px (`--radius-sm…xl`) |
| Подпись формы | **Срезанный угол с рамкой по срезу** — правила ниже |
| Свечение | Только позади элемента, анимируется прозрачность (`docs/27` §3.3) |

### Срезанный угол

- **Рамка идёт по срезу** так же, как по остальному краю. Просто обрезанный
  элемент, где рамка обрывается на срезе, не делаем. Образец — первый блок
  `directions/directions-2026-10-c.html`.
- **Срез — только у того, что главное на экране.** Сейчас это четыре места
  (T-0013):
  - кнопка «Играть» / «Продолжить» на главной;
  - карточка награды дня, когда её можно забрать;
  - окно выбора улучшения и выбранная в нём карточка;
  - окно экрана смерти.

  Новое место со срезом — решение тимлидов строкой здесь, а не находка в
  вёрстке.
- **Обычные карточки, плитки, фишки, кнопки второго плана — со скруглением.**
  Если срезать всё, срез перестаёт выделять главное.
- **Размер** — `--cut-md` (10 px) у карточек и окон, `--cut-sm` (8 px) у кнопок.
- **Срезаются два угла по диагонали:** левый верхний и правый нижний.

## Вид боя

Утверждено 06.10.2026 — вариант 3 «цвет по угрозе»
(`directions/directions-2026-10-c.html`, раздел «Забег»). Окончательно
настраиваем в игре, в живом забеге.

| Что | Правило |
|---|---|
| Фон арены | Средний тон, а не чёрный: сумеречный сине-зелёный (центр `#36546a`, край `#263b4c`). На нём сильнее всего читается красный |
| Рядовые враги | Красные, без обводки. Тип различается формой, ступень — тоном и светлым ядром |
| Элита | Горячий оранжево-красный, золотая кайма |
| Босс | Малиновый, крупнее, золотая кайма потолще |
| Тень | Мягкая тень снизу у всех сущностей: «ставит» фигуру на землю и отделяет от фона без мультяшного контура |
| Кристаллы опыта | Яркие и светлые; ценность — цветом и размером. Тёмных кристаллов не бывает |
| Обереги | Бирюза (`secondary`) |
| Герой | Белый |
| Цифры урона | Белые с тенью, крит — жёлтый |

**Главное правило читаемости:** у каждой роли свой цвет, и ни одна роль не
повторяет фон.

| Роль | Цвет |
|---|---|
| Враг | красный |
| Опыт | светлый яркий |
| Своё оружие и обереги | бирюза и тёплый |
| Герой | белый |
