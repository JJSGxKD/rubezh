Первый забег v2 — пролог, который кончается победой

Первый забег открывается сразу при первом входе. Его задача — не научить всему, а за 3 минуты дать почувствовать главное: «я сильный, и чем дальше — тем сильнее», увидеть награду-событие и уйти с победой, а не со смертью. Подсказки — по одной и только когда нужны. Механика и числа — meta-v2.md §4.

Победа
Окно-реликвия: время, враги, «Страж повержен». Награды: монеты, окрас «Знахарка», открыта Награда дня и Задания.
уходит победителем — и с целью
Не умирает: пока идёт пролог, оберег не даёт здоровью упасть ниже 25% — вспыхивает щитом. Ошибка учит, а не наказывает. Подсказки — по одной, по событию: идти, собирать, уворачиваться, выбирать. Никаких экранов правил до игры. После победы: «Дальше — бесконечный рубеж: сколько продержишься?» — главная с горящей «Играть». Аналитика: tutorial_step на каждый шаг — воронка по шагам показывает, где уходят.
