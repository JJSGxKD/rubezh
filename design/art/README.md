## Цели

Перевести мир забега с геометрических заглушек на цельный 2D-арт, не
ломая утверждённый «вид боя» (`design/README.md`); найти и исправить
проблемы интерфейса; придумать бесконечное окружение, эффекты и недостающие
звуки — с учётом браузера, Phaser и бюджетных телефонов.

## Исходное состояние (21.10.2026, `dev`)

- Мир забега — фигуры, сгенерированные движком: красные круги, квадраты,
  клинья; герой — белый круг. Фон — сетка 64 единицы. Ни одного файла-ассета
  (`docs/27` §3.5).
- Интерфейс — React-оболочка на токенах «Сумеречного рубежа», в хорошем
  состоянии; находки — точечные (переносы, свечение, вкладки).
- Звук — процедурные рецепты с шинами и правилами грани; музыка удалена (с 31.10 — своя, кодом, Р180).

## Художественное направление

**«Форма-предок»** (`characters.md` §2): два плоских тона без контура,
силуэт существа наследует фигуру своего паттерна, цвет — по угрозе, как
утверждено в «Виде боя». Контур — только у героя. Сравнение с «Лубком» и
«Тенями Нави» — `out/sheet-concepts.png`.

## Инструменты

| Задача | Чем сделано | Почему | Что дальше |
|---|---|---|---|
| Спрайты, декор, эффекты | векторные рисунки кодом (`src/*.mjs`) → Chromium → атлас | генератора изображений в среде нет; рисунок кодом даёт палитровые варианты, ступени и ранги из одного источника и повторяемую сборку | художник на чистовом этапе по эталонам пропорций и цвета; для ручной доводки кадров — Aseprite |
| Атлас | свой полочный упаковщик (`src/build.mjs`) + палитра Pillow (`src/quantize.py`) | формат Phaser JSON-hash, без зависимостей в репозитории | обрезка кадров (A-06); TexturePacker или free-tex-packer — если кадров станет сотни |
| Проверка в масштабе и замеры | прототип на Phaser 3.90 + Playwright | та же версия движка, что в игре; снимки и прогоны повторяемы | замер на телефоне — сценарий в `checklists.md` |
| Аудит интерфейса | живая сборка `dev` с локальным бэкендом + Playwright на трёх ширинах | экраны с данными, а не состояния ошибки | WebView Telegram на устройствах |
| Звук | рецепты проекта, отрисованные синтезатором игры, ffmpeg → OGG | файл звучит так же, как рецепт в игре | лаборатория на телефоне; записанные звуки угроз и наград — на чистовом этапе |

**ИИ-генераторы изображений, звука и музыки в этой работе не
использовались** — в среде их нет. Кандидаты на чистовой этап, **не
проверявшиеся здесь**: генераторы спрайтов с фиксацией стиля (по эталонам
отсюда), генераторы звуковых эффектов, генераторы музыкальных эскизов. До
применения — сверка лицензии с `docs/12-ip-and-licensing.md`: права на
сгенерированное должны позволять коммерческое использование в игре.

## Что не сделано и почему

- **Арт не включён игроку.** Он в движке за флагом разработчика
  (`render/art-atlas.ts`, `render/art-ground.ts`): включать по умолчанию
  без решения по направлению (п. 1) и облику по `id` врага (п. 2) нельзя.
  Атласы берутся прямо из `design/art/out`; переезд на манифест паков —
  `characters.md` §7.
- **Ничего не проверено на телефоне и в WebView Telegram.** Замеры
  прототипа — в SwiftShader (процессорный рендер), цифры относительные.
- **Звуки не прослушаны ушами** — в среде нет вывода звука; проверены
  пики и спектрограммы.
- **Снаряды и блеск кристалла не проверены в движении** — их нет в прототипе.
- **Рисунок кодом проще ручного** — это эталон для чистового этапа, а не
  финальный арт.

## Как пересобрать и посмотреть

```bash
node design/art/src/build.mjs          # атласы, земля, отчёт о весе
node design/art/src/previews.mjs       # листы концепций, бестиария, героя, эффектов
node design/art/src/frame-fit.mjs      # влезает ли рисунок врага в кадр атласа: края и нужный запас `pad`
node design/art/src/portraits.mjs      # портреты героя вектором для меню (после build.mjs)
node design/art/src/logo.mjs           # логотип v2: словесный знак, руна, значок приложения, иконка вкладки → out/brand и оболочка
node design/art/src/bot-art.mjs        # бренд для картинок бота → backend/api/src/common/card/brand-art.ts (после logo.mjs и portraits.mjs)
node design/art/src/promo.mjs          # промо 1:1, 16:9, 21:9: сила, награда, вызов → out/promo/*.png и mockups/promo-*.html
node design/art/src/promo-presets.mjs  # стартовые пресеты генератора промо: фоны WebP и документы promo-kit → apps/admin/src/screens/promo/art-starters, mockups/promo-presets-v2.html
node design/art/src/platform-kit.mjs   # значки площадок 16…1024 и превью Mini App 640×360 → out/platform (после logo.mjs и promo.mjs)
python3 design/art/src/cvd.py кадр.png -o полоса.png  # кадр глазами дейтеранопа, протанопа и тританопа — проверка нового цвета
pnpm dev:telegram                       # нужен для следующей строки
node design/art/src/render-sounds.mjs  # OGG предложенных звуков
node design/art/src/music.mjs          # музыка: лобби, пульс, босс → packages/app-shell/src/audio/music (нужен ffmpeg с libopus)
node design/art/src/admin-overflow.mjs # админка на 390 без боковой прокрутки (нужна запущенная панель)
STATE=state.json PREVIEWS=1 node design/art/src/contrast-audit.mjs  # контраст подписей на экранах и окнах забега из витрины — по пикселям под текстом (нужна запущенная оболочка)
STATE=state.json node design/art/src/a11y-audit.mjs  # зона касания, имена для диктора, крупный шрифт 130 и 150 % (нужна запущенная оболочка)
npx http-server . -p 8090               # затем открыть в браузере:
#   /design/art/prototype/arena.html — прототип
#   /design/art/mockups/ui-fixes.html — макеты интерфейса
#   /design/art/audio/index.html — прослушка звуков
#   /design/art/audio/music.html — прослушка музыки, пульс с боссом вместе
```

Сборке нужны Playwright с Chromium (`PLAYWRIGHT_MODULE`), Pillow и ffmpeg.
Прототип в адресе понимает `enemies`, `mode=sprites|shapes`, `zones`,
`decor`, `patches`, `fx`, `ground`, `auto`, `area`, `x`, `y`, `clean=1`;
объект сцены для автоматических прогонов — `window.__arena`.
