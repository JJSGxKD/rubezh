# Очередь дизайнера

Работы для дизайнера (`claude-design-N`) по решениям владельца от 24.10.2026
(`docs/35-stage4-plan.md` Р143–Р157, WP51). Дизайнер берёт пункт сверху,
делает материалы в `design/art/` по своим правилам (`README.md`,
`direction-v2.md`) и открывает PR с меткой `release: none`; код экранов —
задачи исполнителей, их тимлид заводит по готовым материалам.

Кадры и превью — в галерею (`README.md`, «Кадры и промо — не в git»), в git —
исходники в `src/`, атласы, листы и макеты.
