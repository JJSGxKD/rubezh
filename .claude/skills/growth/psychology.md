# Психология продвижения и граница честности

Справка скилла `growth`: принципы, которые работают, и где каждый
скатывается в манипуляцию. Основано на marketingskills
(`marketing-psychology`), переложено на правило Р11. Лицензии —
[`../THIRD_PARTY.md`](../THIRD_PARTY.md). Запрещённые приёмы интерфейса —
`ui-design`, `onboarding-and-ethics.md` §5.

| Принцип | Как применить у нас | Граница — нельзя |
|---|---|---|
| Социальное доказательство | настоящие числа: «Выбор игроков» считается, «играют сейчас» — по онлайну | накрутка, выдуманные «127 смотрят», ложные отзывы |
| Нулевая цена | бесплатный забег без стен | «бесплатно» со скрытой платой |
| Немедленная выгода | «с первого забега» | обещать то, что придёт через месяц |
| Меньше трения | вход в одно касание, продолжить с того же места | — |
| Умолчание | только бесплатное и безопасное | предвыбор платного, тихое продление |
| Выбор из немногого | три набора, один рекомендован, если это правда | искусственно слабый вариант-приманка |
| Цель видна | полоса батл-пасса, прогресс задания | искусственное торможение с платным ускорением |
| Пик и конец | сильный финал забега и экран «что получил» | — |
| Незавершённое | напоминание о настоящей цели | давление и вина |
| Подача цены | «за сезон», сравнение с понятной единицей | дробить цену, пряча итог |
| Взаимность | сначала дать (подарок новичку, награда дня) | подарок с обязательством «отработать» |
| Нога в двери | малый шаг ведёт к большему | постепенно затягивать в платное |
| Дефицит, срочность | только настоящий срок: сезон с датой, Ярмарка недели | сбрасываемый таймер, вечное «осталось 3», «последний шанс» каждую неделю |
| Неприятие потерь | один раз и спокойно назвать настоящую потерю («сезон кончится в воскресенье») | «потеряешь прогресс», если не потеряет; стыд |
| Якорь, контраст | только настоящая прежняя цена, честное «до и после» | придуманная зачёркнутая цена, «дверь в лицо» |
| Рамка | «90 % выживают» и «10 % гибнут» — при одинаковой правде | прятать вторую половину |
| Владение | своя сборка, облик, Застава | — |

**Модель Фогга:** поведение = мотивация × способность × подсказка. Нет
действия — не хватает одного из трёх; сначала упрощать, а не уговаривать.

**Эффект кобры:** стимул может породить обратное. Награда за приглашения
привлекает фармеров (`referrals.md` §5); новый стимул — сначала на малой
доле.

**Второй порядок:** скидка поднимает выручку сегодня и приучает ждать
скидок завтра.

**Проклятие знания:** тексты проверяются на человеке, который игру не знает.

**Тест перед выпуском:** сделали бы мы так же, если бы игрок видел, зачем мы
это делаем? Если нет — граница перейдена.
