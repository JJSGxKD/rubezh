# Ревью звука и звуковой набор

Справка скилла `game-sound`: правила единства набора, чек-лист ревью и
тесты, которых пока нет. Основано на ui-sound-design-skill (Danny Williams,
режим ревью) и agentic-gamedev-skills (abagames, звуковые наборы и их
проверка). Лицензии — [`../THIRD_PARTY.md`](../THIRD_PARTY.md).

## 1. Звуковой набор

- **Единство тембра:** одна-две основные волны и одно семейство модуляции на
  игру. Saw или square «для одного звука» — только с записанной причиной.
- **Четыре семейства:** награда (светлое, вверх), опасность (средне-высокий
  шум и диссонанс), урон (низ и короткий шум), смена состояния (свой мотив
  120–350 мс). Тембр семейства не меняется по ходу забега.
- **Проверка семейств:** игрок с закрытыми глазами называет событие по
  звуку.
- Фоновые события меты (награда дня, колесо) — чуть позади боевого отклика.
- Новый звук «на всякий случай» не заводится: каждый отвечает на вопрос, что
  игрок по нему узнаёт.

## 2. Чек-лист

**Критично**
- [ ] нет рампы к нулю; перед рампой `setValueAtTime`;
- [ ] `stop()` позже огибающей;
- [ ] в шаге симуляции ничего не добавлено; шум от `rng`, без
  `Math.random()`.

**Высокое**
- [ ] длина в границах категории (`engineering.md` §1);
- [ ] пик слоя не выше 0,8, Q не выше 10;
- [ ] шум для удара, тон для высоты;
- [ ] своя полоса частот, соседи по шине в ней не живут;
- [ ] спад экспоненциальный.

**Набор**
- [ ] момент классифицирован (короткий, джингл, тишина), есть строка-цель;
- [ ] тембр своего семейства;
- [ ] редкость читается по шкале (`catalog.md` §3);
- [ ] вариативность в бюджете, звук узнаётся;
- [ ] частый звук слышен поверх самого плотного боя.

**Микс**
- [ ] уровни сверены в своей группе одновременности, замер — на выходе
  цепочки;
- [ ] «срезано гранью» в лаборатории не выросло, угрозы не перекрыты;
- [ ] слушали вполголоса на телефоне: резкий шум не режет;
- [ ] отчёт различает «слушал» и «измерил».

Формат находки: `файл:строка — [правило] что не так`; в конце — таблица
«пройдено / нет» по разделам.

## 3. Тесты, которых пока нет

Сейчас `app-shell/test/audio.test.ts` проверяет рецепт схемой. Стоит
добавить отдельной задачей:

1. **Бюджет:** `dur` не длиннее 0,6 с у оружия, толпы, интерфейса и
   персонажа и не длиннее 1,6 с у наград и угроз; исключения — поимённо с
   причиной; слоёв не больше шести.
2. **Порядок пиков в группе:** угрозы и урон выше наград, награды выше
   оружия, оружие выше толпы.
3. **Покрытие:** у каждого сигнала забега есть звук или явная отметка
   «молчит».
4. **Строй:** подборы и лесенка — в ладу; тревога, диссонанс и шум —
   исключения с причиной.
5. **Рендер-метрики** (нужна подмена `OfflineAudioContext` в тестах —
   решить отдельно): не тишина, без клиппинга, хвост не длиннее `dur`.
