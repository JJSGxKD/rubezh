# Словарь: описание словами → параметры рецепта

Справка скилла `game-sound`. Основано на ui-sound-design-skill (Danny
Williams, «словарь») и переложено на наши слои синтеза. Лицензии —
[`../THIRD_PARTY.md`](../THIRD_PARTY.md).

Наши слои (`audio/recipes.ts`, `synth.ts`):
- `tone` — волна, глайд `f0 → f1`, `attack`, `peak`, `decay`, `detune`;
- `hiss` — шум через фильтр с разверткой;
- `bell` — FM: `ratio`, `index`;
- `swell` — `attack`, `hold`, `release`, фильтр, расстройка.

Огибающая — линейный подъём и экспонента вниз.

| Говорят | Что менять |
|---|---|
| ярче | `f0`/`f1` вверх; фильтр `hiss` выше (1 500 → 3 000 Гц); `bell.index` вверх; волна sine → triangle → saw |
| мягче | `peak` ниже; `attack` 3 → 10–20 мс; фильтр ниже; sine или triangle |
| теплее | lowpass около 1 200 Гц вместо 3 000; sine или triangle вместо saw; убрать шум выше 4 кГц |
| темнее, тяжелее | `f0` на октаву вниз; lowpass около 800 Гц; `decay` длиннее |
| резче, «щёлкает» | `decay` 0,15 → 0,05; `attack` 1–3 мс; шум highpass 4–6 кГц на 15–20 мс |
| полнее | второй голос `detune` ±7 центов; слой октавой ниже |
| тоньше | один sine; highpass около 500 Гц; убрать нижний слой |
| металлический | `bell` с нецелым `ratio` (1,4; 2,76; 3,5), `index` 1,2–2, модулятор гаснет быстрее несущей |
| живой | тихий `hiss` полосой; `variants` и `pitch` |
| короче, суше | `dur` и `decay` вниз; `send` 0 |
| протяжнее | `swell`; `hold`; `release` 0,3–0,8 с; `send` выше |
| игривый | `f0` выше; глайд вверх и обратно |
| как пузырь | sine, глайд 2 000 → 400 Гц за 0,08 с, `decay` около 0,06 |
| глухой стук | sine 600 → 100 Гц за 0,1 с, `peak` около 0,35 |
| щелчок | `hiss` полосой 2 000 Гц, Q 2, 20–50 мс; «клавиша» — 3 500 Гц, Q 8, 25 мс |
| взмах, свист | `hiss` полосой, развертка 500 → 4 000 Гц за 0,2 с, Q 1; тяжёлый — 200 → 2 000 за 0,3 с |
| стеклянный | `bell` `ratio` 3,5, 1 500–3 000 Гц, `decay` 0,3–0,6, чистый хвост |
| деревянный | sine или triangle 180–400 Гц с глайдом вниз и короткий шум 800–1 500 Гц |
| тревожный | saw или square, lowpass 1 500–2 500 Гц, малая секунда или тритон, двойной импульс |
| низкий рык | saw 60–120 Гц вниз, lowpass 400–900 Гц, шум lowpass |
| «дороже» (награда) | восходящий интервал; `bell`; `send` 0,2–0,4; больше обертонов; чуть длиннее |

**Правило правки:** на «нравится, но…» — один-два параметра за заход. На
«совсем не то» — другая основа (другой рецепт или слой), а не новые числа у
этой.

**От образца к параметрам.** Если дизайнер приносит звук-образец, подбирать
«похоже по характеру», а не копию:
- атака короче 5 мс → `attack` 1–3 мс; 5–20 мс → около 10 мс; дольше 50 мс → `swell`;
- спад короче 50 мс → перкуссия; 50–200 мс → «с ударом»; дольше → протяжный `decay`;
- яркость: центр спектра выше 4 кГц — очень ярко, 1–2 кГц — нейтрально,
  ниже 0,5 кГц — темно; яркость задают фильтр и волна;
- тональный → `tone`, шумовой → `hiss`;
- гармоники целые → `tone`, нецелые → `bell` с высоким `ratio` или шум с фильтром;
- высота падает или растёт → глайд `f0 → f1` в ту же сторону.

Лицензию образца — по `docs/12`: коммерческое использование обязательно.
