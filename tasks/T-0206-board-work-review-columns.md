# T-0206. Доска — в «В работе» и «На ревью» видно, кто, сколько висит и чего ждёт

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0206.json)](README.md#значки-статуса) [![T-0205](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0205.json&label=T-0205)](T-0205-board-who-waits-owner-runner.md) [![T-0207](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0207.json&label=T-0207)](T-0207-pr-runner-and-launcher-lines.md)

## Зачем

В разделах «В работе» и «На ревью» сейчас два столбца: задача и кто взял
(или номер PR). Не видно, какой человек запустил поток, сколько задача
висит, сколько раз её возвращали и на ком она стоит. После задачи у обоих
разделов и у «Доработки» — одинаковые столбцы, и зависшее видно сразу.

## Решения

Решение владельца от 24.10.2026 (разбор входящих, вопрос В6) — четыре
столбца: исполнитель и человек, сколько висит, круги доработки, чего ждёт.

Решения `claude-lead-1` от 24.10.2026:

- **Столбцы** «В работе», «На ревью» и «Доработки»: «Задача», «Поток»,
  «Запустил», «Висит», «Кругов», «Чего ждёт», «PR» (у «В работе» PR нет —
  столбца нет).
  - «Поток» — поле `owner` из ветки задачи, как сейчас («неизвестно», если
    не прочитано).
  - «Запустил» — значение строки `Запустил:` из описания PR (T-0207); нет
    PR или строки — «—».
  - «Висит» — целые сутки: у «В работе» — от коммита захвата `chore(tasks):
    Взять T-NNNN в работу` в ветке задачи, у PR — от `createdAt`. Меньше
    суток — «сегодня», иначе «N дн». От трёх суток — с пометкой «⚠️ »
    впереди.
  - «Кругов» — сколько в PR коммитов с заголовком `chore(tasks): Продолжить
    T-NNNN после ответа` (их делает `pnpm task resume`, по одному на
    круг); `0` — «—».
  - «Чего ждёт» — `waitingOn` из T-0205: «исполнителя · доработка»,
    «исполнителя · CI красный», «тимлида · вопрос», «тимлида · приёмка»,
    «владельца». У «В работе» — «исполнителя».
- **Дата захвата** — `git log -1 --format=%cI --grep "^chore(tasks): Взять
  T-NNNN в работу$" origin/task/T-NNNN`; коммита нет — «—» и без пометки.

## Как сейчас

- `scripts/tasks/board-page.mjs` — разделы «Доработка», «В работе» и «На
  ревью» в `renderBoardPage`: столбцы «Задача, Исполнитель, PR, Вёл»,
  «Задача, Взял» и «Задача, PR».
- `scripts/tasks/git-io.mjs` — `openPrs()` после T-0205 уже даёт `body`,
  `createdAt`, `statusCheckRollup`; коммитов PR в ответе нет.
- `scripts/tasks/task.mjs` — `runStatusJson` собирает `owners` по веткам и
  передаёт их странице.
- `waitingOn(pr)` — в `scripts/tasks/board.mjs` после T-0205.

## Шаги по порядку

1. **`git-io.mjs`.**
   - `openPrs()` запрашивает ещё `commits` (у `gh pr list` — `messageHeadline`
     каждого коммита).
   - `export function claimedAt(id)` → ISO-дата коммита захвата или `null`
     — по правилу из «Решений», через `tryGit`.
2. **`board.mjs`.**
   - `export function reworkRounds(pr, id)` → число коммитов PR с
     заголовком `chore(tasks): Продолжить ${id} после ответа`.
   - `export function launchedBy(body)` → значение строки `Запустил:` или
     `null` (та же регулярка, что в `pr-check`, T-0207; вынести её в общее
     место нельзя — `board.mjs` не импортирует `scripts/release/`, поэтому
     регулярка повторяется, и тест сверяет их на одних примерах).
   - `export function hangingDays(since, now)` → целые сутки или `null`.
3. **`board-page.mjs`.** Столбцы трёх разделов по «Решениям»; данные
   приходят готовыми полями записи (`owner`, `launchedBy`, `days`,
   `rounds`, `waiting`), страница их только форматирует. Подписи «Чего
   ждёт» — словарь `{ executor: "исполнителя", lead: "тимлида", owner:
   "владельца" }` и `why` через « · ».
4. **`task.mjs`.** `runStatusJson` для каждой записи «В работе», «На
   ревью» и «Доработки» считает поля шага 3: `claimedAt` — только для «В
   работе».
5. **`tasks/README.md`** — в абзаце о доске (раздел «Значки статуса» или
   «Автопоток», где описана страница) — одна строка о новых столбцах и
   пометке «⚠️» от трёх суток.

## Чего не трогаем

- Разделы «Ждут тимлида», «Ждут владельца» и строку счётчиков — они из
  T-0205.
- Команду `pnpm task board` в терминале: столбцы — только на странице.
- «Вклад» — задача T-0208.

## Тесты

Первым коммитом.

- `tasks-board.test.ts`:
  - `reworkRounds` — два коммита «Продолжить T-0001 после ответа» и один
    чужой → 2; коммит другой задачи «Продолжить T-0002 …» не считается;
  - `launchedBy` — «Запустил: помощник ivan_2» → «помощник ivan_2»; строки
    нет → `null`; те же примеры, что в `pr-check.test.ts` (T-0207), дают
    тот же ответ;
  - `hangingDays` — 23 часа → 0; 49 часов → 2; `since: null` → `null`.
- `tasks-board-page.test.ts`:
  - «На ревью»: PR, открытый 4 суток назад, с одним кругом и красным CI →
    строка с «⚠️ 4 дн», «1», «исполнителя · CI красный»;
  - «В работе»: задача без коммита захвата → «Висит» — «—»;
  - PR без строки `Запустил:` → «—» в столбце «Запустил».
