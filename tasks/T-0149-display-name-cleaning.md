# T-0149. Чистка ников — символы, длина, мат, замена пустого

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0149.json)](README.md#значки-статуса)

## Зачем

Ник игрока — имя с площадки как есть. В панели (снимок от 15.10.2026) ник из
повторяющихся декоративных знаков растянулся на всю ширину строки, а рядом
стоит ник с матом. Те же ники видят игроки в рейтинге и «Друзьях». Эта задача
— чистая функция чистки. Применение при входе, хранение исходника и ручная
смена — T-0150 и T-0151.

## Решения

Решения пользователя от 15.10.2026:

- ник, от которого после чистки ничего не осталось или в котором мат, —
  **username площадки, если он чистый, иначе «Игрок NNNN»**;
- **мат и оскорбления фильтруются словарём** — русский и английский, с
  латиницей вместо кириллицы и цифрами вместо букв. Словарь в публичном
  репозитории — это нормально.

Правила чистки — `claude-lead-1`, 15.10.2026, по порядку применения:

1. `normalize("NFKC")`: «𝓐𝓵𝓮𝔁» и полноширинные буквы → обычные.
2. Выбросить:
   - управляющие (`\p{Cc}`);
   - служебные (`\p{Cf}`), кроме U+200D (склейка эмодзи);
   - частные и неназначенные (`\p{Co}`, `\p{Cn}`);
   - охватывающие знаки (`\p{Me}` — например U+0489, им рисуют «кружева» как на
     снимке);
   - блоки сверхширокого рисунка: клинопись U+12000–U+1254F, египетские
     иероглифы U+13000–U+1345F, лигатуры U+FDFA–U+FDFD, рамки и блоки
     U+2500–U+259F, шрифт Брайля U+2800–U+28FF (из него рисуют картинки).
3. Надстрочные знаки (`\p{Mn}`): не больше трёх подряд после одного знака —
   этого хватает вьетнамскому и индийским письменностям, а «залго» — нет.
   Лишние выбрасываются. U+FE0F и U+FE0E (вид эмодзи) не считаются.
4. Пробелы (`\p{Z}`, табуляция) — схлопнуть в один, обрезать края.
5. Нет ни одной буквы или цифры (`\p{L}`, `\p{N}`) — ника нет («empty»).
6. Длиннее 24 графем (`Intl.Segmenter`, `granularity: "grapheme"`) — 23
   графемы и «…».
7. Мат — по правилам «Словарь» ниже. Найден — ника нет («profanity»).

**Замена.** Ника нет → тот же путь для `username`: шаги 1–7, но без шага 6 —
username короче. Чистый username → он, без `@`. Иначе
`Игрок ${String(parseInt(accountId.slice(0, 8), 16) % 10000).padStart(4, "0")}`:
номер постоянный для аккаунта и разный у соседей в рейтинге, а id площадки
не светится.

**Словарь** (`display-name-words.ts`):

- **три свёртки**, корень ищется в каждой. Во всех трёх: строчные буквы,
  `ё→е`, повторы одной буквы схлопнуты.
  - *похожие буквы* — латиница и цифры, которые выглядят как кириллица:
    `a→а, b→б, c→с, e→е, h→н, k→к, m→м, o→о, p→р, t→т, x→х, y→у, 0→о, 3→з,
    6→б, @→а` («cyka» → «сука»);
  - *транслит* — сначала сочетания `sh→ш, ch→ч, zh→ж, ya→я, yu→ю`, потом
    буквы `a→а, b→б, c→ц, d→д, e→е, f→ф, g→г, h→х, i→и, j→й, k→к, l→л, m→м,
    n→н, o→о, p→п, r→р, s→с, t→т, u→у, v→в, y→ы, z→з` и цифры `0→о, 1→и,
    3→з, 4→ч, 6→б, @→а` («huj» → «хуй», «p1zdets» → «пиздетс»);
  - *латиница* — для английских корней: `0→o, 1→i, 3→e, 4→a, 5→s, @→a`;
- **два вида корней:**
  - `anywhere` — ищется в нике целиком без пробелов и разделителей (`.`,
    `-`, `_`, `*`): `хуй, хуе, хуя, хую, пизд, ебат, ебан, ебал, ебло, ебуч,
    мудак, мудил, пидор, пидар, гандон, залуп, шлюх`;
  - `wordStart` — только в начале слова, иначе ложные срабатывания
    («корабля», «Сукачёв»): `бля, сука, суки, сучк, сучар, ебу, еби; fuck,
    shit, bitch, cunt, dick, nigg, faggot`;
- **исключения** — подстроки, которые вырезаются из свёртки до поиска корней:
  `страхуй, психуй, сукно, сукровиц, сукач, dickens`. Список дополняется по ложным
  срабатываниям — одной строкой и тестом.

## Шаги по порядку

1. **Тесты первым коммитом** (раздел «Тесты»).
2. **`display-name-words.ts`** — `ANYWHERE_ROOTS`, `WORD_START_ROOTS`,
   `ALLOWED_WORDS`, `foldForSearch(text)`, `foldLatin(text)`. Комментарий:
   словарь публичный осознанно; новое ложное срабатывание — в `ALLOWED_WORDS`
   с тестом.
3. **`display-name.ts`** — без импортов Nest и Prisma:
   ```ts
   export type NameVerdict = "ok" | "trimmed" | "symbols" | "empty" | "profanity";
   export interface CleanName { name: string; verdict: NameVerdict }
   export function cleanName(raw: string): { name: string | null; verdict: NameVerdict }
   export function displayNameFor(raw: string, username: string | null, accountId: string): CleanName
   ```
   - `cleanName`: `name: null` при `empty` и `profanity`. `symbols` — что-то
     выброшено, `trimmed` — обрезано по длине, `ok` — без изменений.
   - `displayNameFor`: ник или замена; `verdict` — исходного ника.
   Комментарий над правилами — почему каждый блок выброшен (ширина рисунка).

## Тесты

`backend/api/test/display-name.test.ts`:

- `"Оленька"`, `"Marina Krasovskaya"`, `"Жамила 🚀"`, `"Александр🥖"` → без
  изменений, `ok`;
- семья эмодзи с U+200D → склейка сохранена;
- `"Nguyễn"` (вьетнамский) и `"हिन्दी"` → без изменений;
- `"Z̷̢̛a̸l̵g̶o̴"` с десятком знаков на букву → не больше трёх, `symbols`;
- строка из U+0489 и пробелов → `empty`;
- `"𒐫𒐫𒐫"` → `empty`; `"Вася 𒐫"` → `"Вася"`, `symbols`;
- `"⣿⣿⣿ Петя"` → `"Петя"`;
- RLO U+202E в середине → выброшен;
- `"𝓐𝓵𝓮𝔁"` → `"Alex"`;
- 30 букв → 23 и «…», `trimmed`;
- мат: `"Huj Vsem"`, `"х.у.й"`, `"П1ZДЕЦ"`, `"pizdets"`, `"FUCKER"`,
  `"Блядина"`, `"сука"`, `"cyka"` → `profanity`;
- не мат: `"Корабля"`, `"Рубль"`, `"Застрахуй"`, `"Сукно"`, `"Scunthorpe"`,
  `"Оскорблённый"`, `"Хлебушек"`, `"Сукачёв"`, `"Dickens"`, `"Психуй"` → `ok`;
- `displayNameFor`:
  - пустой ник, username `"tolik"` → `"tolik"`;
  - пустой ник, username с матом → `"Игрок NNNN"`;
  - username `null` → `"Игрок NNNN"`, номер одинаковый на повторе;
  - `accountId` `"00000000-…"` → `"Игрок 0000"`.
