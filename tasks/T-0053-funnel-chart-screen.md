# T-0053. Воронка в панели — полосами, сравнение с прошлым периодом, подсветка источников

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0053.json)](README.md#значки-статуса) [![T-0049](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0049.json&label=T-0049)](archive/T-0049-admin-shell-responsive.md)

## Зачем

Экран «Воронка» — одна таблица из девяти вех на источник. Где теряем
новичков, можно найти, только читая цифры. Пользователь 07.10.2026 включил
воронку в первые макеты панели. Макет — `design/screens/admin-funnel.html`.

## Решения

- **Период** — «7 дней · 30 дней · 90 дней · Свой период». «Свой» — прежние
  два поля дат; по умолчанию — 30 дней, как сейчас.
- **Выбор периода — общим компонентом** `ui/period-picker.tsx` (решение
  `claude-lead-1` от 24.10.2026 по аудиту дизайнера AD-02,
  `design/art/direction-v2.md` §4.6): чипы пресетов над полями «Свой», а
  выбранный период — подписью `22.09–22.10` в формате `ДД.ММ`, независимо от
  языка браузера (голые поля даты в браузере с английской локалью показывают
  `mm/dd/yyyy`). Пресеты — свойством компонента: этот же выбор дальше возьмут
  «Выгрузки», «Доля флага» и «Игроки». Тест `period-picker.test.ts` — пресет
  → пара дат; подпись периода; «Свой» с перевёрнутыми датами — ошибка у
  поля.
- **«Сравнить с прошлым периодом»** — переключатель. Прошлый период той же
  длины — второй запрос к тому же маршруту: сервер не меняется.
- **Воронка полосами** — по строке «Все источники» (`funnelTotal`):
  - ширина полосы — доля от «Вход»;
  - справа — доля от входа, доля от прошлой вехи, изменение к прошлому
    периоду в процентных пунктах (у «Входа» — изменение числа аккаунтов, %);
  - тонкая черта на полосе — где был прошлый период;
  - сравнение выключено — черты и изменений нет.
- **«Больше всего теряем»** — отметка над вехой с наибольшей потерей от
  прошлой среди первых шести (вход … 5 забегов): дальше потеря ожидаема.
- **Таблица источников** — та же, ячейка подсвечена по доле к строке «Все
  источники»:
  - выше на 3 п. и больше — зелёным;
  - ниже — красным;
  - насыщенность растёт с разницей и не выше 30%.

  Сортировка — по аккаунтам или по любой вехе.
- **Доля флага** (`FlagSplitPanel`) — без изменений, ниже.

## Шаги по порядку

1. **Тесты первым коммитом** (раздел «Тесты»).
2. **`api/funnel.ts`** — чистые помощники:

   ```ts
   /** Пресет периода от «сейчас»: последние N суток по Москве, сегодня включительно. */
   export function presetPeriod(days: 7 | 30 | 90, now: Date): Period;
   /** Прошлый период той же длины, вплотную перед этим. */
   export function previousPeriod(period: Required<Period>): Required<Period>;
   export interface FunnelBar { step: FunnelStep; title: string; count: number; ofFirst: number; ofPrev: number | null; deltaPts: number | null }
   /** Полосы по строке «Все источники»; `before` — та же строка прошлого периода или `null`. */
   export function funnelBars(total: FunnelRow, before: FunnelRow | null): FunnelBar[];
   /** Индекс вехи с наибольшей потерей от прошлой среди первых шести; потерь нет — `null`. */
   export function worstStep(bars: readonly FunnelBar[]): number | null;
   /** Тон ячейки: доля строки против доли «Все источники». */
   export function heatTone(share: number, base: number): { tone: "up" | "down" | "flat"; strength: number };
   ```

   - `deltaPts` — `(ofFirst − ofFirstПрошлого) × 100` с одним знаком после
     запятой;
   - `heatTone`:
     - `|share − base| < 0,03` → `flat`;
     - иначе `up` или `down`;
     - `strength = min(0,3; |разница| × 2)`.
3. **Новый `screens/funnel/funnel-chart.tsx`:**
   - `FunnelChart({ bars, worst, compare })` по макету:
     - сетка `150px 1fr 300px`;
     - полоса 26 px, число внутри при доле больше 8%;
     - черта прошлого периода — 2 px, `bg-text/55`;
     - изменения — `text-success` или `text-danger`;
     - отметка «больше всего теряем» — строкой над вехой: «N% не доходят от
       «…» до «…»»;
   - на телефоне (`useNarrow`):
     - название и число над полосой во всю ширину;
     - доли — под ней.
4. **`FunnelScreen.tsx`:**
   - сверху ряд:
     - чипы периода;
     - «Свой период» раскрывает прежнюю форму дат;
     - выбор площадки — фильтр строк по `platform` на клиенте, значения — из
       строк ответа;
     - переключатель сравнения;
     - «Обновить»;
   - панель «Воронка новичков» — `FunnelChart`, подзаголовок — период,

   - панель «По источникам»:

## Сценарий и интерфейс

По макету:

- 30 дней с сравнением;
- полосы с чертами;
- отметка между «2 забега» и «5 забегов»;
- таблица источников с подсветкой.

За период никто не пришёл — вместо полос и таблицы «За период никто не
пришёл», как сейчас. Снимки на 390, 768 и 1440 px снимают тимлиды.

## Тесты

Первым коммитом, `apps/admin/test/funnel-chart.test.ts`:

- `presetPeriod(7, now)` — с начала суток шесть дней назад по Москве до
  `now`;
- `previousPeriod` — та же длина, вплотную;
- `funnelBars`:
  - доли от первой и прошлой;
  - `deltaPts` при прошлом;
  - `before: null` → `deltaPts: null`;
  - `entered 0` — без деления на ноль;
- `worstStep`:
  - на числах макета → индекс «5 забегов»;
  - потеря на 8-й вехе в расчёт не идёт;
- `heatTone`:
  - `0,85` против `0,85` → `flat`;
  - `0,92` против `0,85` → `up` с силой 0,14;
  - `0,60` против `0,85` → `down` с силой 0,3 (потолок).
