# T-0356. Панель — список первым, форма «Новое …» и «Изменить» в окне: Задания, Главная, Журнал, Флаги

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0356.json)](README.md#значки-статуса)

## Зачем

В разделах «Задания», «Главная», «Журнал» и «Флаги» форма «Новое …» стоит над
списком. В раздел заходят обычно затем, чтобы найти и поправить то, что уже
есть, а существующее уезжает под форму. На телефоне до списка приходится
листать два экрана. После задачи раздел открывается списком. «Новое
задание» — кнопка в шапке списка, она открывает форму в окне; на телефоне
окно выезжает листом снизу. «Изменить» у строки открывает ту же форму.

## Решения

Находка AD-05 аудита дизайнера (`design/art/direction-v2.md` §4.6, принцип
«сначала то, что есть, потом форма»). Решения `claude-lead-1` от
01.11.2026:

- **Окно — общий `Dialog`** (`ui/dialog.tsx`): он уже на телефоне становится
  листом снизу. Новый размер `size="wide"` — `min(1080px, 100vw - 32px)`,
  для форм с предпросмотром: колонка формы и кадр телефона 390 px встают
  рядом. На узком экране предпросмотр — под формой внутри листа.
  Предпросмотр по-прежнему не ужимается (§4.6: иначе он соврёт о переносах).
- **Кнопки формы — в подвале окна** (`footer`), подвал не прокручивается
  вместе с формой. Кнопка отправки связана с формой через `form="<id>"`, как
  уже сделано в `NetworkTasksPanel.tsx` и `ProxyDialog.tsx`.
- **Несохранённое не теряется.** Если форма изменена, то Escape, щелчок мимо
  окна и × спрашивают через `ConfirmDialog`: «Закрыть без сохранения?» —
  «Закрыть» и «Вернуться». Форма не изменена — окно закрывается сразу.
  Чистая функция `isDirty(initial, current)` — в `ui/form-dialog.tsx`,
  сравнение по значениям, без учёта порядка ключей.
- **Сохранили — окно закрылось**, список обновился, тост — тот же, что
  сейчас.
- **Кнопка «Новое …»** — в `actions` панели списка: «Новое задание», «Новый
  слайд», «Новая строка», «Новый флаг». У «Заданий» несколько панелей по
  группам — кнопка одна, в первой панели.
- **Подсказки пустого списка** указывают на кнопку, а не на форму «выше».
  Например, «Пусто — заведите задание выше» → «Пусто — заведите кнопкой «Новое
  задание»».

## Сценарий и интерфейс

- **Открыл «Задания»** — сразу группы заданий; в шапке первой панели —
  «Новое задание».
- **Нажал «Новое задание»** — окно «Новое задание»: слева форма, справа кадр
  телефона «Так увидит игрок». Внизу окна — «Завести» и «Отмена».
- **Ввёл заголовок и нажал Escape** — «Закрыть без сохранения?»;
  «Вернуться» — форма с введённым на месте.
- **«Изменить» у задания** — то же окно с заголовком «Задание daily_runs_3»,
  поля заполнены.
- **Телефон** — окно листом снизу во всю ширину, предпросмотр под формой,
  кнопки — в подвале листа.
- **Ошибка сохранения** — окно не закрывается, ошибка — в окне над
  кнопками, как сейчас под формой.

## Тесты

Первым коммитом, `apps/admin/test/form-dialog.test.ts`:

- `isDirty({ a: 1, b: "x" }, { b: "x", a: 1 })` → `false`;
- `isDirty({ a: 1 }, { a: 2 })` → `true`;
- вложенные значения: `isDirty({ r: { coins: 5 } }, { r: { coins: 5 } })` →
  `false`, при `coins: 6` → `true`;
- `null` и пустая строка различаются: `isDirty({ t: null }, { t: "" })` →
  `true`. Формы приводят пустое поле к `null` сами, до сравнения.
