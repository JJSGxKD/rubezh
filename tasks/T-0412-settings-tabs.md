# T-0412. Раздел «Настройки» — вкладки по группам с адресом вместо одной ленты

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0412.json)](README.md#значки-статуса)

## Зачем

«Настройки» — лента из двадцати с лишним панелей, по одной на группу
каталога: «Уведомления команде», «Магазин», «Реклама» и дальше. Нужную
группу ищут прокруткой, ссылку на неё не отправить. После задачи у
раздела вкладки-чипы по группам с адресом `#/settings/<группа>`. Прежние
ссылки на настройку `#/settings/<ключ>` открывают её группу и подсвечивают
строку.

## Решения

- **Р201** (`docs/35-stage4-plan.md`), решение тимлида по входящему
  владельца:
  - «Настройки» — `#/settings/<группа>`, по вкладке на группу каталога;
  - вид — чипы с числом настроек: групп больше двадцати, строка с чертой
    не поместилась бы;
  - прежние ссылки `#/settings/<ключ>` открывают вкладку группы этого ключа
    и подсвечивают строку;
  - это перестановка интерфейса: правка, сброс и проверки настроек те же.

Решения `claude-lead-1` по коду:

1. **Вкладки строит панель из ответа сервера.** Группа — поле `group` у
   строки настройки, порядок — как в каталоге (`groupSettings`). Сервер не
   меняется.
2. **В адресе — короткое латинское имя группы** из таблицы
   `SETTING_GROUP_SLUGS` в панели: `#/settings/ads`, а не
   `%D0%A0%D0%B5…`. Группа, которой нет в таблице (её завела новая задача),
   всё равно получает вкладку: в адресе тогда её название
   (`encodeURIComponent` делает `hrefOf`). Новая группа — строка в таблице.
   Её дописывает задача, которая заводит группу, или тимлид.
3. **Ключ и имя группы не путаются.** Ключи настроек всегда с точкой
   (`ads.test-mode`), имена групп — без точки. Это проверяет тест.
4. **Разбор адреса** (`id` маршрута), по порядку:
   - это ключ настройки из ответа → вкладка его группы, строка
     подсвечена и прокручена в центр, как сейчас;
   - это имя группы из таблицы или её название → эта вкладка;
   - нет или не узнали → первая группа.
5. **Вид — чипы, как «Категория» в «Фильтре имён»** (`NamesScreen.tsx:116–129`):
   - `role="tablist"`, переносятся на следующую строку;
   - подпись — «Название · N», N — число настроек группы;
   - `TabBar` (строка с чертой) здесь не подходит: двадцать вкладок не
     влезают даже в 1440 px.
6. **Смена вкладки** — `navigate({ section: "settings", id: <имя группы> })`.
   Начатая правка и плашка итога («Сохранено…») при этом сбрасываются:
   строки прежней вкладки уже не видно.

## Сценарий и интерфейс

- **Открыли раздел из меню** → `#/settings`, открыта первая группа
  («Уведомления команде»). Над таблицей — чипы всех групп «Название · N»,
  у выбранной — акцентная рамка и фон.
- **Нажали «Реклама · N»** → адрес `#/settings/ads`, ниже — только панель
  «Реклама». «Назад» в браузере возвращает прежнюю группу.
- **Ссылка «Выключить в настройках»** из «Рекламы» (`#/settings/ads.test-mode`)
  → вкладка «Реклама», строка «Тестовые показы рекламы» подсвечена и прокручена.
- **Неизвестный хвост** (`#/settings/nope`) → первая группа, без
  подсветки.
- **Сохранили или сбросили** → плашка итога над чипами, вкладка та же.
  Сменили вкладку — плашка и открытое поле правки пропадают.
- **Загрузка, ошибка, нет сети** — как сейчас: `Loading` и `ErrorNotice` с
  «Повторить» вместо чипов и таблицы.
- **Пусто** (сервер не вернул настроек) — чипов нет, текст «Настроек нет».
  На проде так не бывает, но пустой экран без слов читается как поломка.
- **Ограничение доступа** — раздел, как и сейчас, только с `settings.edit`.
- **Телефон (390 px)** — чипы переносятся строками, страница без боковой
  прокрутки.

Снимки — первая группа, «Реклама» с подсветкой по ссылке, на 390 и 1440 px.
Поток с dev-сервером кладёт их в PR, без него их делает тимлид на приёмке.

- `apps/admin/test/settings-tabs.test.ts`, строки — по образцу `CHAT` из
  `apps/admin/test/settings.test.ts`, с разными `key` и `group`:
  - `SETTING_GROUP_SLUGS`: значения уникальны и подходят под

  - `settingsTabs` на строках групп «Магазин», «Реклама», «Магазин» →
    две вкладки в порядке появления: `shop` с двумя строками, `ads` с
    одной;

    `id: "Новая группа"`, `hrefOf({ section: "settings", id: tab.id })` →
    `#/settings/%D0%9D…` и обратно `parseRoute` → то же `id`;
  - `settingsTabOf(null, tabs)` → первая вкладка, `focus: null`;
  - `settingsTabOf("ads", tabs)` → вкладка `ads`, `focus: null`;
  - `settingsTabOf("Реклама", tabs)` → вкладка `ads`;
  - `settingsTabOf("ads.test-mode", tabs)` при строке с этим ключом в
    группе «Реклама» → вкладка `ads`, `focus: "ads.test-mode"`;
  - `settingsTabOf("ads.unknown", tabs)` → первая вкладка, `focus: null`;
  - `settingsTabOf("ads", [])` → `{ tab: null, focus: null }`.
- Существующие `settings.test.ts` и `routes.test.ts` зелёные без правки.
