# T-0471. «Мой проект» — отчёт закрытого месяца и подтверждение участником

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0471.json)](README.md#значки-статуса) [![T-0469](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0469.json&label=T-0469)](T-0469-ledger-confirmations-payouts.md) [![T-0455](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0455.json&label=T-0455)](archive/T-0455-my-project-screen.md)

## Зачем

Кабинет участника (T-0455) показывает черновик месяца. Когда месяц закрыт
(Р222), участник должен увидеть настоящий отчёт по форме
`docs/11-revenue-split.md` §5 — выручку, расходы построчно, налог, займ, долю
каждого — и подтвердить его или оспорить с комментарием. Без этого выплата
ему ждёт.

## Решения

- `docs/35-stage4-plan.md`, **Р222**, **Р218**; `docs/11-revenue-split.md`
  §4–§5.
- Закрытый месяц в кабинете заменяет черновик: плашка «Черновик» исчезает,
  вместо неё — статус: «Ждёт твоего подтверждения», «Ты подтвердил»,
  «Ты оспорил: <комментарий>», «Выплачено N ₽».
- Оспорить — комментарий обязателен; решение можно поменять, пока не
  выплачено.

## Как сейчас

- Кабинет «Мой проект» — `screens/my-project/MyProjectScreen.tsx` (T-0455).
- Сервер (T-0469): `GET /admin/my-project/periods/:p` — отчёт из снимка,
  своя строка, статус; `POST /admin/my-project/periods/:p/confirm`
  `{ decision: "confirmed" | "disputed", comment? }`.

## Шаги по порядку

1. `api/my-project.ts` — схемы и вызовы закрытого месяца.
2. `ClosedMonth.tsx` — для закрытого месяца вместо черновика:
   - статус сверху (см. «Решения»);
   - **моя часть** — крупно ₽, рядом $;
   - отчёт по `docs/11` §5: реклама и платежи по площадкам, расходы
     построчно, налог с режимом и ставками, займ (было, транш, осталось),
     прибыль к разделу, все участники с долями и суммами, остаток
     владельца;
   - кнопки «Подтверждаю» и «Есть вопрос» (окно с комментарием); после
     решения — «Изменить решение», пока нет выплаты.
3. `MyProjectScreen.tsx`: закрытый месяц — `ClosedMonth`, открытый — как
   сейчас; в списке месяцев метка «ждёт подтверждения».
4. `docs/29-admin-panel.md` §6.6 — закрытый месяц в кабинете.
