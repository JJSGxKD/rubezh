# T-0049. Каркас панели — меню со значками и поиском, телефон, таблицы карточками

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0049.json)](README.md#значки-статуса)

## Зачем

Панель сейчас — только для широкого экрана:

- сетка `208px 1fr` на телефоне ломается;
- таблицы уезжают вбок;
- у меню нет поиска.

Команда отвечает на жалобы и сообщения из потоков чата с телефона, и ссылка
из чата должна открываться там же. Решения пользователя от 07.10.2026 —
`docs/29-admin-panel.md` §4, «Телефон» и «Облик».

## Решения

- **Телефон — полноценно:**
  - до 768 px меню — лист слева по кнопке в шапке;
  - таблицы — карточками;
  - окна — листом снизу.
- **Облик — палитра игры, но строже:** Russo One — только заголовки
  разделов и крупные числа, без срезов и свечений.
- **Меню:**
  - значок у каждого раздела;
  - поиск раздела, клавиша `/` ставит в него курсор;
  - активный раздел — подложка и черта акцента слева.
- **Шапка:**
  - «группа / раздел» и подсказка, как сейчас;
  - справа аватар и имя — меню аккаунта с ролями и «Выйти».
- **Таблица на телефоне — карточкой строки:**
  - главное поле крупно;
  - остальные — парами «название значение»;
  - колонку можно скрыть на телефоне.

## Как сейчас

- **`apps/admin/src/screens/Shell.tsx`:**
  - сетка `grid-cols-[208px_1fr]`;
  - `nav` прилипает к окну;
  - шапка — путь, подсказка, имя, роли бейджами, «Выйти».
- **`apps/admin/src/routes.ts`:**
  - `SECTION_GROUPS`: у раздела `id`, `title`, `hint`, `permission`;
  - `visibleGroups`, `parseRoute`, `hrefOf`, `resolveRoute`.
- **`apps/admin/src/ui/kit.tsx`:**
  - `Column<T>` — `title`, `render`, `align`, `help`;
  - `DataTable` — `<table>` в `overflow-x-auto`.
- **`apps/admin/src/ui/dialog.tsx`** — Radix `Dialog` по центру, ширина
  `min(760px, 100vw-32px)`.

8. **Документы** — раздел «Документы».

## Чего не трогаем

- Экраны разделов — они получают телефон через `DataTable` и `Dialog` сами.
- Права, группы, порядок разделов, подсказки.
- Счётчики у разделов в меню (макет) — отдельная задача: для них нужен лёгкий
  маршрут, а не сводка целиком.

## Сценарий и интерфейс

По макету `design/screens/admin-shell.html`:

- **ПК** — меню со значками и поиском, шапка с меню аккаунта, таблица
  игроков.
- **Телефон** — шапка с кнопкой меню, список игроков карточками, меню
  листом.

Снимки на 390, 768 и 1440 px снимают тимлиды.
