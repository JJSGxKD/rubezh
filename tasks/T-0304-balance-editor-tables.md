# T-0304. Панель «Баланс» — таблицы контента по разделам, правка ячейки с прежним числом, ошибка формы строкой под записью, список правок черновика

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0304.json)](README.md#значки-статуса) [![T-0303](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0303.json&label=T-0303)](T-0303-content-drafts-server.md)

## Зачем

Сервер хранит версии и черновики контента (T-0303), а правят их пока через
код. После задачи у геймдизайнера в панели раздел «Баланс»:
- таблицы по разделам;
- правка числа прямо в ячейке — ячейка подсвечена, рядом прежнее число;
- ошибка формы — строкой под записью;
- список правок черновика.

Проверка симуляцией — T-0305.

## Решения

Решения владельца — 25.10.2026: редактор баланса, шаг 1 — песочница;
разделы первой волны — враги и таймлайн, оружие и навыки, подборы, сундуки и
опыт. Цены и награды — T-0309.

Макет — `design/art/mockups/admin-balance.html`, снимок
`design/art/out/preview/admin-balance.png` (`design/art/direction-v2.md`
§4.6, AD-13).

Решения `claude-lead-1` от 25.10.2026:

- **Раздел** «Баланс»:
  - группа меню «Контент»;
  - право `content.view`, правка — `content.edit`.
  - Шапка:
    - «В игре: v{N} · {дата}» — пока это версия из репозитория;
    - «Черновик: {n} правок · {автор}»;
    - кнопки «Новый черновик», «Проверить» (T-0305).

    «В staging» и «Опубликовать» — шаг 2 (T-0306), в этой задаче их нет.
- **Вкладки-разделы:**
  - «Враги» — имя, здоровье, скорость, урон, опыт, угроза, поведение,
    стойкость; элита и босс — меткой;
  - «Ступени» — секунда, вес, множители;
  - «Таймлайн» — отрезки (секунда, поток с темпом, выброс, события) и кривая
    бесконечного режима;
  - «Оружие» — уровни строками, эволюции;
  - «Навыки» — уровни, категория;
  - «Открытия» — уровень аккаунта → оружие, навыки, слоты;
  - «Подборы и сундуки» — `drops`, `chests`;
  - «Опыт и сложность» — кривая опыта, `difficulty`.
- **Правка ячейки:**
  - только числа, переключатели и выбор из списка (паттерн — из
    реализованных, стихия — из списка). Новых записей и удаления в шаге 1
    нет: новое понятие — код (`docs/19` §2);
  - изменённая ячейка — жёлтый тон, рядом мелко «было {n}»;
  - Esc — вернуть.

  Сохраняется сразу запросом правки по пути (T-0303).
- **Ошибка формы** — 422 сервера строкой под записью:
  - красный тон;
  - текст сервера и «Было {n}»;
  - ячейка остаётся с введённым, черновик не меняется.
- **Список правок** — боковой лист «Правки»: путь словами («Волк · урон 7 →
  9»), у каждой — «Вернуть».
- **Имена** — по ключам `nameKey` из словаря игры: панель не показывает id,
  где есть имя. Панель не импортирует пакеты игры (`layer-boundaries.test.ts`),
  поэтому словарь имён приходит с сервера вместе с версией (`names`, T-0303).

«Баланс» → «Новый черновик» → «Враги» → Волк, урон 7 → 9:
- ячейка жёлтая, «было 7»;

- «Правки» — «Волк · урон 7 → 9», «Вернуть».

- загрузка;
- ошибка с «Повторить»;
- нет черновика — «Новый черновик»;
- нет права правки — только чтение.
