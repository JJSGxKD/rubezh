# T-0275. Раздел «Промо» в панели — пресеты команды: список, новый пресет, правка в редакторе, публикация партнёрам

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0275.json)](README.md#значки-статуса) [![T-0273](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0273.json&label=T-0273)](T-0273-promo-studio-server.md) [![T-0274](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0274.json&label=T-0274)](T-0274-promo-editor-fabric.md)

## Зачем

Сервер пресетов (T-0273) и редактор (T-0274) готовы, а места в панели нет.
После задачи у маркетолога есть раздел «Промо» с вкладкой «Пресеты»:
- список макетов с превью;
- новый пресет с нуля, копией или из стартового;
- правка в редакторе;
- публикация — для команды или и для партнёров.

Генератор материала из пресета — вкладка «Материал» (T-0276).

## Решения

Решение владельца — `docs/35-stage4-plan.md` Р159: пресеты делает команда,
партнёр берёт опубликованные.

Решения `claude-lead-1` от 25.10.2026:

- **Раздел** «Промо»:
  - в группе меню, где «Ссылки» и «Промокоды»;
  - подсказка «Макеты и материалы для постов, сторис и партнёров»;
  - право `promo.studio.edit`;
  - значок `Palette` из `lucide-react`;
  - вкладки «Материал» (T-0276) и «Пресеты» — в этой задаче только
    «Пресеты», без пустой вкладки.
- **Список:**
  - карточки: превью, название, формат («Сторис 1080×1920»);
  - метки «Черновик» или «Опубликован», «Команде» или «Партнёрам»;
  - фильтры — формат, статус, «Архив»;
  - порядок — `sort`, затем новые.
- **«Новый пресет»** — лист: название, формат и начало:
  - «Пустой»;
  - «Копия пресета …»;
  - стартовый пресет.

  Стартовые — `screens/promo/starters.ts`, документы `promo-kit` из
  цветов `@bh/design-tokens`, без арта:
  - «Промокод · сторис» — заголовок, `{code}` крупно, `{reward}`, QR, логотип;
  - «Приглашение · пост 1:1» — заголовок, текст, QR, логотип.

  Арт для пресетов рисует дизайнер (пункт 15 очереди, `design/art/backlog.md`).
- **Правка** — `PromoEditor` в режиме `team`:
  - `assets.upload` — загрузка профилем `promo_asset`;
  - `assets.list` — картинки этого пресета.

  Сохранение:
  - «Сохранить» — с `updatedAt`; 409 `promo_template_stale` — «Пресет
    изменили, пока вы работали» и «Открыть свежий» (своя правка — в буфер
    обмена JSON, чтобы не пропала);
  - уход со страницы с несохранённым — подтверждение.
- **Превью пресета** — при сохранении:
  - выгрузка `exportImage` в масштабе, где короткая сторона — 240 точек;
  - WebP, загрузка профилем `promo_asset` → `thumb_image_id`.

  Сбой превью сохранение не останавливает.
- **Примеры для проверки** — переключатель «С примером»: `vars` —
  - `code: "ПРИМЕР"`;
  - `reward: "300 монет"`;
  - `link` — адрес бота.
- **Публикация:**
  - «Опубликовать» и «Снять с публикации»;
  - «Партнёрам» — с подтверждением «Партнёры увидят пресет в кабинете и
    смогут менять отмеченные слои»;
  - у опубликованного для партнёров без единого слоя с `partner` —
    предупреждение «Партнёр сможет только подставить свой код».
- **«В архив»** — с подтверждением; из архива — «Вернуть».

## Сценарий и интерфейс

«Промо» → «Пресеты» → «Новый пресет» → «Зимний код», сторис, стартовый
«Промокод · сторис» → редактор:
1. Поменять заголовок и цвет.
2. Отметить у заголовка «Партнёр может менять текст».
3. «Сохранить».
4. «Опубликовать» → «Партнёрам» → подтверждение.

В списке — превью и метки «Опубликован · Партнёрам».

Ширины 1280 и 1024. Состояния:
- загрузка;
- ошибка с «Повторить»;
- пусто — «Пресетов ещё нет» и «Новый пресет»;
- нет права — раздела нет в меню.

## Тесты
