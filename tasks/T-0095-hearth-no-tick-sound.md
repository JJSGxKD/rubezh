# T-0095. «Очаг» не звучит на каждый такт ауры

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0095.json)](README.md#значки-статуса)

## Зачем

Оружие «Очаг» бьёт по зоне вокруг игрока несколько раз в секунду, и на каждый
такт играл звук. На живом тесте он сильно раздражает. После задачи «Очаг»
в бою молчит, а остальные виды оружия звучат как раньше. Сам «Очаг» никуда не
девается: зона, урон и поджог те же, их по-прежнему видно.

## Решения

- **Решение участника 1 от 13.10.2026 (тест):** убрать звук на каждый всплеск
  «Очага»; другие виды оружия не трогаем.
- **Звук задаётся данными, не кодом движка.** Какое оружие чем звучит, решает
  таблица `WEAPON_SOUNDS` в режиссёре звука. У «Грозы» записи в ней нет — она
  звучит сигналом `strikes`, а не срабатыванием оружия; «Очаг» теперь так же
  без записи. Признака «тихий тик» в симуляции и в `core-game` не вводим:
  сигнал `cues.weapons.hearth` остаётся, просто его никто не озвучивает.
- **Рецепт `hearth` удаляется вместе с записью.** Без него звук не рендерится
  в банк зря, а звуковая лаборатория не показывает звук «Очаг — такт ауры»,
  которого в бою нет. Сохранённые на устройстве правки рецептов с неизвестным
  id отбрасываются сами (`isSoundId`, `lab-overrides.ts:88`).

## Сценарий и интерфейс

Что слышит и видит игрок:

- **Бой с «Очагом»** — зона и поджог как раньше; такта ауры не слышно. Звуки
  попадания по игроку, подбора, гибели врагов и остального оружия — как раньше.
- **Бой с «Очагом» и «Искрой»** — слышна «Искра», «Очаг» молчит.
- **Звуковая лаборатория** (только у тех, кому открыта) — в списке звуков нет
  «Очаг — такт ауры»; симуляция боя работает как раньше.
- Загрузки, ошибок и «нет сети» у правки нет.

## Тесты

Первым коммитом. `packages/app-shell/test/audio.test.ts`, в описание
`"план звуков забега"` (после теста про «Грозу», строка ~89):

- `planCueSounds(cues({ weapons: { hearth: 3 } }), 0)` → `[]`: «Очаг»
  не просит ни одного звука, даже с большим счётом;
- `planCueSounds(cues({ weapons: { hearth: 1, spark: 1 } }), 0)` → ids
  `["spark"]`: рядом звучит остальное оружие;
- для каждого из `spark`, `knife`, `wardstone`: `cues({ weapons: { [id]: 1 } })`
  даёт ровно один запрос с `id` этого звука (остальные виды не потеряны).

В описание `"рецепты звуков"` и рядом с тестом «правка с ошибкой пропускается»
(строки 59-71):

- `Object.hasOwn(SOUND_RECIPES, "hearth")` → `false`;
- хранилище с правкой `hearth: { ...SOUND_RECIPES.spark }` и правкой
  `uiTap` (как в соседнем тесте, через `memoryStorage` и `LAB_OVERRIDES_KEY`):
  `Object.keys(readLabOverrides(storage))` → `["uiTap"]`: старая правка «Очага»
  не ломает чтение.

Существующий тест `"проходят схему лаборатории"` (строки 50-58) перебирает
рецепты сам и новых кейсов не требует.
