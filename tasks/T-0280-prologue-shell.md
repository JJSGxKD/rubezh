## Зачем

Движок (T-0278) и сервер (T-0279) пролога готовы, а игрок его не видит.
После задачи новичок:
1. нажимает «Играть» на первом экране и сразу попадает в пролог;
2. получает подсказки по одной, когда они нужны;
3. на первом выборе видит «Советуем»;
4. через три минуты побеждает Стража;
5. видит окно «Рубеж удержан!» с наградой.

Главная до победы — только «Играть». После победы появляются «Награда дня»
и «Задания» с меткой «Новое».

## Решения

Решения владельца:
- Р151 — пролог, подсказки по событию, окно победы;
- 25.10.2026 — за пролог монеты и самоцветы, разделы открываются победой.

Сценарий — `design/art/meta-v2.md` §4.2. Раскадровка экранов —
`design/art/mockups/prologue-v2.html` (31.10.2026, `src/prologue-board.mjs`):
11 кадров на 320 — подсказки, «Советуем», оберег, сундук, Страж, окно
победы, выход и главная до и после. Ранний набросок по времени —
`mockups/first-run-v2.html`.

Решения `claude-lead-1` от 25.10.2026:

- **Когда пролог** — `prologueDone` из профиля (T-0279) ложно. Правило
  `state/prologue.ts`:
  - `prologueDone === false` → «Играть» запускает `mode: "prologue"`,
    сложность `easy`;
  - профиль не пришёл за 2,5 с (как `playedBefore` в `state/first-run.ts`) и
    `useMeta.runs === 0` → пролог;
  - иначе — обычный забег.

  Правило сложности T-0190 (`runs === 0` → `easy`) заменяется этим: пролог и
  есть обучающий забег.
- **Начало** — строка поверх поля на 3 с: «Навь идёт к рубежу. Держи его».
  Листа «Перед забегом» в прологе нет.
- **Подсказки по событию** — `state/hints.ts`, по одной. Порядок
  `HINT_ORDER`:
  1. `move` — на старте;
  2. `gems` — первый кристалл на поле;
  3. `choose` (новая) — первый выбор улучшения: «Выбери улучшение — «Советуем»
     подойдёт для начала»;
  4. `dodge` — появилась первая элита: «Золотая кайма — элита: бьёт больнее.
     Держись на расстоянии — с неё упадёт сундук». Ударов по кругу у упыря
     пролога нет (паттерн `chase`) — прежний текст про светящуюся землю
     обещал то, чего игрок не увидит (поправка дизайнера 31.10.2026).

  В прологе подсказки показываются всегда, даже если их уже видели на этом
  устройстве: пролог — первый забег аккаунта.
- **«Советуем»** — у карточки с `recommended` (T-0278):
  - метка «Советуем» в углу;
  - светлая кайма тоном `accent`.

  Выбор не навязан: любая карточка берётся одним касанием.
- **Оберег** — событие `ward` рисует движок. Оболочка при первом обереге
  показывает подсказку «Оберег не даст пасть в первом бою» один раз.
- **Страж** — баннер T-0124 «Страж рубежа!» тот же.
- **Окно «Рубеж удержан!»** — по `prologueWon`, окном-реликвией T-0232:
  - заголовок «Рубеж удержан!», время «3:04»;
  - награда — «+500 монет», «+10 самоцветов», числа из ответа записи забега;
  - строка «Открыты Награда дня и Задания»;
  - строка цели «На 10-м уровне — облик Знахарки»;
  - кнопка «На главную».

  Награда приходит откликом счёта (#460).
- **Выход до победы** — «Сдаться» в прологе спрашивает: «Пролог можно
  пройти позже — он начнётся заново». Итог без окна смерти — сразу главная.
- **Главная до победы:**
  - только «Играть» и строка «Первый бой — три минуты»;
  - виджеты награды дня и заданий, вкладка «Задания» скрыты.

  Вход по ссылке на скрытый экран (стартовый параметр) — главная с той же
  строкой.
- **Главная после победы** — виджеты на месте, у «Награды дня» и
  «Заданий» метка «Новое» до первого открытия. «Играть» с подписью «Дальше —
  бесконечный рубеж: сколько продержишься?» до второго забега.

## Сценарий и интерфейс

Новый аккаунт:
1. «Играть» → пролог без листа «Перед забегом».
2. Подсказка «веди пальцем» → первый кристалл → «Выбери улучшение», на одной
   карточке «Советуем».
3. Элита — подсказка уворота → большой сундук.
4. Страж → «Рубеж удержан!» +500 монет, +10 самоцветов.
5. «На главную» — виджеты награды дня и заданий с «Новое».

Проверить 320, 390, 768, ландшафт 667×375. Состояния:
- нет сети при записи забега — окно победы с наградой «придёт, когда
  вернётся связь»;
- выход посреди пролога → следующий запуск снова пролог.

## Тесты

Первым коммитом, `prologue-shell.test.ts`:
- правило запуска:
  - `prologueDone: false` → пролог;
  - `true` → обычный;
  - профиль не пришёл и `runs === 0` → пролог;
- подсказки в прологе: порядок `move` → `gems` → `choose` → `dodge`; уже виденные на
  устройстве — всё равно показываются;
- главная до победы — без виджетов награды дня и заданий; после — с «Новое»,
  которое гаснет первым открытием;
- окно победы показывает числа из ответа сервера, а не постоянные.
