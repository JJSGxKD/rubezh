# T-0476. Определения агентов команды — модель, усилие и инструменты в файле, а не в промпте

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0476.json)](README.md#значки-статуса)

## Зачем

Правило `CLAUDE.md` «у каждого субагента модель и усилие задаются явно»
выполняется вручную в каждом промпте конвейера; ревьюеры иногда делают
лишнее (перезапускают CI, ставят в очередь), потому что инструменты у них
те же, что у исполнителя. Задача (Р224, D) заводит определения агентов в
`.claude/agents/`: роль, модель, усилие, инструменты и скилл — в файле.

## Решения

- `docs/35-stage4-plan.md`, **Р224** (D); модели ролей — `tasks/README.md`,
  «Роли и кодовые имена».
- Агенты:
  - `rubezh-executor` — Sonnet, все инструменты, начинает со скилла
    `take-task`;
  - `rubezh-reviewer` — Sonnet (для денег и миграций конвейер подставит
    Opus), **только чтение**: Read, Grep, Glob, Bash для `git`/`gh pr view|diff|checks`
    и `node scripts/tasks/task.mjs diff-check`; без Edit и Write; начинает со
    скилла `review-pr`;
  - `rubezh-fixer` — Sonnet, все инструменты, правит только по замечаниям,
    без новых задач;
  - `rubezh-scout` — Haiku, только чтение, выбор задачи и поиск работы
    конвейера.
- Формат файла — по документации Claude Code (фронтматтер `name`,
  `description`, `tools`, `model`); сверить с актуальной документацией.

## Как сейчас

- `.claude/agents/` нет; модели и правила — в промптах сценария конвейера
  тимлида.

## Шаги по порядку

1. Четыре файла `.claude/agents/rubezh-*.md`: описание роли, когда
   вызывать, что запрещено (общие правила — ссылкой на `CLAUDE.md` и
   `tasks/README.md`, не копией).
2. `scripts/test/claude-agents.test.ts`: фронтматтер каждого файла
   разбирается; у ревьюера и разведчика нет `Edit`/`Write`; модели — из
   разрешённого списка.
3. `tasks/README.md`, «Роли и кодовые имена» — таблица агентов и как
   конвейер их вызывает (`agentType`); `CLAUDE.md`, абзац «Субагенты и
   workflow — экономно» — ссылка на определения.

## Чего не трогаем

- Скиллы — агенты на них ссылаются.

## Сценарий и интерфейс

- Конвейер вызывает ревью как `agentType: "rubezh-reviewer"` — промпт
  короче, а изменить файлы ревьюер не может.
