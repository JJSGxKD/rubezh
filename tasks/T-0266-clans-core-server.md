# T-0266. Дружина — сервер, ядро: создать, вступить по ссылке или заявкой, выйти, исключить, до 20 участников

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0266.json)](README.md#значки-статуса) [![T-0247](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0247.json&label=T-0247)](T-0247-player-card-server.md)

## Зачем

Игроку не с кем держать рубеж вместе, кроме списка друзей. После задачи
можно собрать дружину до 20 человек:
- создать её;
- позвать по ссылке;
- принять заявку в открытую дружину из списка;
- выйти или исключить участника.

Рейтинг, босс недели и подарки — T-0267, экран — T-0268.

## Решения

Решения владельца — `docs/35-stage4-plan.md`:
- **Р154** — Дружина: клан до 20, общий рейтинг, босс дружины раз в
  неделю, подарки;
- **поправка от 24.10.2026** — вступить можно по ссылке участника или
  заявкой из списка открытых дружин.

Решения `claude-lead-1` от 24.10.2026:

- **Таблицы:**
  - `clan (clan_id uuid, public_id varchar(12) unique, name varchar(24), name_key varchar(24) unique, is_open boolean, created_by, created_at, renamed_at)`, где `name_key` — имя в нижнем регистре без пробелов по краям;
  - `clan_member (account_id PK, clan_id, role 'leader'|'member', joined_at)` — один игрок, одна дружина;
  - `clan_request (clan_id, account_id, created_at)`, ключ — пара;
  - `clan_left (account_id PK, left_at)` — для паузы вступления.
- **Создать** — `POST /api/v1/clans { name, isOpen }`:
  - с 5-го уровня аккаунта;
  - не в дружине;
  - имя 3–24 знака по тем же правилам, что ник (проверка и запрещённые слова — модуль смены ника, T-0151);
  - имя уникально без учёта регистра.

  Создатель — лидер.
- **Вступить по ссылке** — `POST /api/v1/clans/:publicId/join` с меткой
  ссылки участника: сразу участник, если есть место. Ссылка дружины —
  стартовый параметр с парой `clan`, как у карточки (T-0254, `docs/24`).
- **Заявка** — `POST /api/v1/clans/:publicId/requests` только в открытую;
  лидер — `accept` или `decline`. Принятие при полной дружине — 409.
- **Выйти** — `POST /api/v1/clans/leave`:
  - лидер уходит — лидером становится самый давний участник;
  - ушёл последний — дружина удаляется;
  - после выхода — 24 часа без вступления (`clan_left`): против перескоков ради награды босса.
- **Исключить** — лидер, `POST /api/v1/clans/members/:publicId/kick`.
  Исключённому — та же пауза 24 часа.
- **Переименовать** — лидер, не чаще раза в 7 дней.
- **Список открытых** — `GET /api/v1/clans?query=` — поиск по началу имени,
  до 30 строк. Порядок — по рейтингу недели (T-0267), до него — по числу
  участников.
- **Своя дружина** — `GET /api/v1/clans/me`: участники с `publicId`, именем,
  обликом и знаком (порт `PublicIdentity`), ролью; у лидера — заявки.
- **Уведомления:**
  - `clan_request` — лидеру;
  - `clan_accepted` — принятому;
  - `clan_kicked` — исключённому;

  Все три — виды ленты (`notification-kinds.ts`).
- **Ограничение аккаунта** `clans` в `RESTRICTION_KINDS` (`restriction-catalog.ts`, как `friend_gifts`): заблокированному —
  нельзя создавать и вступать.
- **Лимиты** — создание 3 в сутки на игрока, заявки 20 в сутки, остальное —
  как у друзей.

## Тесты

Первым коммитом.

- `clans.test.ts` (чистые):
  - переход лидерства — к самому давнему;
  - имя «Рубеж» и « рубеж » — один ключ;
  - пауза 24 ч после выхода.
- `clans.integration.test.ts`:
  - создать на 4-м уровне → 409; на 5-м → лидер;
  - два одинаковых имени → второе 409;
  - вступить по ссылке → участник; 21-й → 409;
  - заявка в закрытую → 409; в открытую → лидер принял → участник;
  - выход лидера → лидер — самый давний; выход последнего → дружины нет;
  - после выхода вступить раньше 24 ч → 409;
  - две одновременные заявки на последнее место — участником становится один.
