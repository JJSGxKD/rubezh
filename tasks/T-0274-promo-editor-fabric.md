# T-0274. Редактор промо на Fabric.js — холст, слои, текст, картинки, QR, отмена и выгрузка PNG/JPEG

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0274.json)](README.md#значки-статуса) [![T-0272](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0272.json&label=T-0272)](T-0272-promo-kit-model.md) [![T-0218](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0218.json&label=T-0218)](T-0218-partner-cabinet-links-promo.md)

## Зачем

Генератор промо (Р159) — свой редактор на Fabric.js. После задачи в панели
есть компонент редактора `PromoEditor`. Его встраивают экран пресетов
команды (T-0275), генератор материалов (T-0276) и кабинет партнёра (T-0277).
Он:
- открывает документ `promo-kit`;
- даёт править слои мышью и с клавиатуры;
- отдаёт документ обратно;
- выгружает картинку в полном размере.

Экранов в этой задаче нет — только компонент и его витрина.

## Решения

Решение владельца от 25.10.2026 — `docs/35-stage4-plan.md` Р159: редактор
свой, на **Fabric.js** (MIT). Polotno SDK отклонён: платная лицензия от
$199 в месяц и неясная оплата из России.

Решения `claude-lead-1` от 25.10.2026:

- **Зависимость** `fabric`:
  - последняя стабильная версия, точной версией, не младше двух недель;
  - только в `apps/admin`.

  У пакета для Node есть необязательные зависимости `canvas` и `jsdom` —
  браузеру они не нужны. Если pnpm их ставит, они исключаются строкой
  `ignoredOptionalDependencies` в `pnpm-workspace.yaml`. В
  `onlyBuiltDependencies` ничего не добавляется. Решение и причина — в PR.
- **Отдельный чанк** — `PromoEditor` грузится через `lazy()`: Fabric не входит
  в первую загрузку панели. В PR — размер чанка из сборки.
- **Документ — источник истины.** Холст Fabric — только отображение:
  - каждое изменение на холсте превращается в новый `PromoDoc` (`fromCanvas`);
  - отмена и повтор — стопка документов, 50 шагов;
  - сохранять в Fabric-JSON нельзя — только `PromoDoc`.
- **Перевод** — `fabric-doc.ts`, чистыми функциями без DOM, для тестов:
  - `layerToObject(layer, ctx)` → опции объекта Fabric;
  - `objectToLayer(object, prev)` → слой.

  `id` слоя хранится в свойстве объекта. Поворот и масштаб Fabric
  сводятся к `x`, `y`, `width`, `height`, `rotation` слоя: `scaleX` и
  `scaleY` не копятся.
- **Инструменты** (режим `team`):
  - **добавить:** текст, картинку, прямоугольник, QR, логотип;
  - **картинка** — из свойства `assets` редактора:
    - `assets.list()` — уже загруженные картинки пресета;
    - `assets.upload(file)` → id картинки — загрузку с профилем `promo_asset`
      даёт экран (T-0275);
    - в витрине — заглушка на `URL.createObjectURL`;
  - **слои:**
    - список по порядку: поднять, опустить, скрыть, закрепить, переименовать;
    - флажок «Партнёр может менять: текст / картинку / цвет»;
  - **свойства выбранного:**
    - текст — шрифт, размер, жирность, цвет, выравнивание, межстрочный;
    - прямоугольник — заливка, скругление, обводка;
    - у всех — прозрачность и поворот;
  - **палитра пресета** — до 8 цветов, из неё же выбирают и команда, и партнёр;
  - **холст:**
    - направляющие к центру и краям холста при перетаскивании;
    - «Вписать» и масштаб 25…200 %;
  - **клавиши:**
    - Delete — удалить;
    - Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z — отмена и повтор;
    - стрелки — сдвиг на 1, с Shift — на 10;
    - Ctrl/Cmd+D — копия слоя.
- **Режим `partner`:**
  - слои с `partner: "none"` не выбираются и не двигаются;
  - разрешённые — только своим действием:
    - текст — правкой на холсте или в поле;
    - картинка — «Заменить своим фото»: файл читается в браузере
      (`URL.createObjectURL`), на сервер не уходит;
    - цвет — из палитры;
  - каждое изменение проходит `applyPartnerEdits` (T-0272).
- **Шрифты** — Russo One и IBM Plex Sans, уже в панели (`@fontsource`).
  Холст рисует текст после `document.fonts.load` обоих — иначе первая
  выгрузка выйдет системным шрифтом.
- **QR** — `uqr`, уже в панели: картинкой из SVG, тёмный на светлом, поле
  тишины не меньше 4 модулей.
- **Переменные** — `vars` в свойствах редактора:
  - на холсте подставлены значения (`resolveDoc`);
  - в поле текста видна переменная `{code}`, на холсте — код;
  - нет значения — на холсте видно `{code}` пунктиром: «подставится при
    выгрузке».
- **Выгрузка** — `exportImage(doc, vars, type)`:
  - отдельный холст в полном размере формата;
  - PNG или JPEG (качество 0,92);
  - имя файла — `rubezh-<формат>-<код или pres>.png`.

  `docProblems` перед выгрузкой:
  - есть проблемы — список над кнопкой;
  - выгрузку не запрещают.
- **CSP панели** — картинки `blob:` для своего фото партнёра. Если сейчас их
  нет в `img-src` — строка в `csp.ts` с причиной.

## Сценарий и интерфейс

Витрина → документ «Сторис с кодом»:
1. Перетащить заголовок к центру — направляющая.
2. Сменить цвет из палитры.
3. Ctrl+Z — вернулось.
4. Добавить QR.
5. «Скачать PNG» — файл 1080×1920, текст шрифтом Russo One, QR читается
   телефоном.

Режим партнёра:
- заголовок не двигается;
- текст с флажком меняется;
- «Заменить своим фото» — фото на месте, в сети запросов загрузки нет.

Ширины панели — 1280 и 1024. На 768 — сообщение «Редактор — на экране от
1024 точек».

## Тесты

Первым коммитом, `promo-editor.test.ts`:
- `layerToObject` → `objectToLayer` возвращает тот же слой — для каждого вида;
- объект с `scaleX: 2` → `width` вдвое больше, масштаб 1;
- стопка: 51 шаг → самый старый вытеснен; отмена после правки обрывает повтор;
- режим `partner`: правка `x` у слоя отклоняется (через `applyPartnerEdits`);
- имя файла выгрузки с кодом `ЗИМА 25` → `rubezh-story-ЗИМА-25.png`.

Снимки витрины (оба режима) и выгруженный PNG — в PR.
