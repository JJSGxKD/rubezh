# T-0030. Отзыв без подписи запуска — строже лимит и потолок карточек в чат

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0030.json)](README.md#значки-статуса)

## Зачем

Форма отзыва принимает отзыв и без подписи запуска площадки. Так отзыв может
оставить игрок, открывший игру вне Telegram. Но `installId` присылает сам
клиент, и скрипт может менять его на каждый запрос. Для отзыва без подписи
лимит только по адресу — 60 в час, и каждый отзыв уходит карточкой в чат
команды. Чат можно забить спамом, а настоящие отзывы потеряются в потоке.
Это пункт аудита («Приёмники без подписи»).

## Решения

- **Отзыв с подписью** (есть `platformUserId`) — как сейчас: лимиты по
  установке и по игроку, карточка в чат.
- **Отзыв без подписи:**
  - свой лимит по адресу — **3 в час**, сверх общих 60. Живому игроку больше
    трёх отзывов в час не нужно;
  - карточки в чат — **не больше 20 в час на всех**, общим счётчиком.
    Сверх потолка отзыв сохраняется в базе, и его видно в выгрузке и в
    `/feedback`, но карточка не отправляется. Лог уровня `log`
    `notify_skipped_unsigned` — не чаще раза в час. Карточку из чата отнять
    нельзя, а сохранённый отзыв не теряется.
- Подпись не становится обязательной: игроки вне Telegram должны иметь
  возможность сказать.

## Как сейчас

- `backend/api/src/modules/ingest/ingest-limits.ts` — `INGEST_LIMITS.feedback`
  (строки 31–37): `ip` 60/час, `install` 5/час, `user` 5/час.
- `IngestGuard` (`ingest/ingest.guard.ts:61-66`) тратит лимит `ip` до
  контроллера и кладёт `ingestIdentity = { platformUserId, ip }`:
  `platformUserId` — из подписи запуска, `null` — без неё.
- `backend/api/src/modules/feedback/feedback.service.ts`:
  - `receive(body, identity, signal)` (строки 42–71): разбор, `enforceLimits`,
    запись в базу, `notify`;
  - `enforceLimits` (строки 74–79): `install` всегда, `user` — только с
    подписью;
  - `notify` (строки 81–102): карточка в `targets.chats().feedback`, ошибка
    отправки — в лог.

  `RateLimiter` уже внедрён (`this.limiter`).
- Карточка без подписи уже подписана «без Telegram ID»
  (`feedback-message.ts:46`).

## Шаги по порядку

1. Тесты первым коммитом (раздел «Тесты»).
2. **`ingest-limits.ts`** — отдельная константа рядом с `INGEST_LIMITS`, с
   комментарием «почему»:

   ```ts
   /**
    * Отзыв без подписи запуска: installId присылает сам клиент, и держит такой
    * отзыв только адрес. Живому игроку больше трёх отзывов в час не нужно, а в
    * чат команды без подписи — не больше 20 карточек в час на всех: сверх
    * этого отзыв сохраняется, но не отправляется.
    */
   export const UNSIGNED_FEEDBACK_LIMITS = {
     ip: { scope: "feedback:unsigned-ip", limit: 3, windowSec: 3600 },
     chat: { scope: "feedback:unsigned-chat", limit: 20, windowSec: 3600 },
   } as const satisfies Record<"ip" | "chat", RateLimit>;
   ```
3. **`feedback.service.ts`:**
   - `enforceLimits(installId, identity)`: без подписи — ещё
     `consume(UNSIGNED_FEEDBACK_LIMITS.ip, identity.ip)`. Отказ — тот же
     `RateLimitedError("Слишком много отзывов, попробуйте позже")`;
   - `notify`: без подписи — сначала `consume(UNSIGNED_FEEDBACK_LIMITS.chat, "all")`:
     - `false` → карточку не отправлять, лог `notify_skipped_unsigned` не чаще
       раза в час. Время последнего лога — поле класса: это лишь
       прореживание лога, состояние реплики здесь допустимо;
     - `true` → отправить, как сейчас.
   - Подписанный отзыв — без изменений.
4. **Документы** — раздел «Документы».

## Чего не трогаем

- `IngestGuard` и общий лимит `ip` 60/час.
- Приёмники событий и отчётов.
- Текст карточки и `feedback-message.ts`.
- Клиент: на 429 форма уже показывает «попробуйте позже».

## Тесты

Первым коммитом, `backend/api/test/feedback.test.ts`. Лимитер — настоящий
`RateLimiter` с недоступным Redis: работает память, как в соседних тестах.
Или подмена с подсчётом.

- без подписи, один адрес: 3 отзыва → сохранены, четвёртый →
  `RateLimitedError`, пятый с другого адреса → сохранён;
- с подписью: лимит по адресу без подписи не тратится — 4 отзыва от одного
  игрока с одного адреса проходят до лимита `user` (5);
- без подписи с 21 разного адреса → 21 сохранён, карточек 20, у 21-го
  отправки нет, в логе `notify_skipped_unsigned` один раз;
- с подписью после исчерпания потолка без подписи → карточка уходит.
