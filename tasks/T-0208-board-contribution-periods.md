# T-0208. «Вклад» на доске — задачи, доработки, ревью, спецификации и PR тимлидов по периодам

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0208.json)](README.md#значки-статуса) [![T-0209](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0209.json&label=T-0209)](T-0209-flow-prompts-per-account.md)

## Зачем

Раздел «Вклад» сейчас считает только влитые задачи — очками по размеру и по
автору PR на GitHub. А все PR открываются с одного аккаунта, ревью и ответы
тимлидов не видны вовсе, и нет периодов: не понять, кто сделал что сегодня
или за неделю. После задачи «Вклад» показывает по каждому потоку и роли
пять видов работы за сегодня, вчера, неделю, месяц и всё время.

## Решения

Решения владельца от 24.10.2026 (разбор входящих, вопросы В3–В5):

- **Пять столбцов:** «Задачи» (штук и очков по размеру), «Доработки»
  (кругов на задачах исполнителя — чем меньше на задачу, тем лучше),
  «Ревью и ответы», «Спецификации», «PR тимлидов».
- **Кто** — кодовое имя и человек: поток или роль (`claude-3`,
  `claude-lead-1`) и «Запустил» из описания PR (T-0207).
- **Периоды** — сегодня, вчера, неделя, месяц и всё время, по Москве и
  календарные: сутки с 00:00 МСК, неделя с понедельника, месяц с первого
  числа.

Решения `claude-lead-1` от 24.10.2026:

- **Откуда что берётся** (всё — из того, что уже есть в `dev` и на GitHub):
  - «Задачи» — влитые PR веток `task/T-NNNN`, по `mergedAt`. Очки — `S` 1,
    `M` 2. Кто — строки `Поток:` и `Запустил:` описания; у старых PR без
    строк — аккаунт из поля `owner` файла задачи, человек — «не указан».
  - «Доработки» — круги из `reworkRounds` (T-0206) у тех же PR, тому же
    потоку и в тот же период, что и задача.
  - «Ревью и ответы» — ревью и комментарии влитых PR (любых веток), чьё
    тело начинается с `**claude-<что угодно>:**`; кто — это кодовое имя;
    период — по `createdAt` ревью или комментария.
  - «Спецификации» — файлы задач, добавленные в `dev`: коммит появления
    файла `tasks/T-*.md` (`git log --diff-filter=A --find-renames`, чтобы
    переезд в архив по T-0204 не считался новым файлом); кто — поле
    `author`; период — дата коммита.
  - «PR тимлидов» — влитые PR не из веток `task/` и не служебные
    (`dev` ↔ `main`), у которых первая непустая строка описания —
    `**claude-…:**`; кто — это кодовое имя; период — `mergedAt`.
- **Строка — участник «кодовое имя · человек»**: «claude-3 · владелец»,
  «claude-3 · помощник ivan_2», «claude-lead-1 · —». У ролей тимлидов,
  ревьюеров и дизайнеров человек не пишется: их сессии не несут строки
  «Запустил».
- **Вид раздела**: вступление, затем по таблице на период. «Сегодня» и
  «Неделя» открыты, «Вчера», «Месяц» и «Всё время» — в `<details>`.
  Столбцы: «Кто», «Задачи», «Очки», «Доработки», «Ревью и ответы»,
  «Спецификации», «PR тимлидов». Строки — по убыванию очков, затем ревью,
  затем по имени. Пустой период — «Пусто.».
- **Вступление**: «Наглядность, а не формула выплат: доли участников
  проекта назначает владелец (`docs/11-revenue-split.md` §3). Время — МСК.»
- **Объём запроса**: `gh pr list --state merged --base dev --limit 1000
  --json number,headRefName,baseRefName,mergedAt,body,commits,reviews,comments`
  одним вызовом. Если ответ не пришёл — раздел с пометкой «Нет данных
  GitHub», как сейчас; спецификации считаются и без GitHub.
- **Логика — в новом файле `scripts/tasks/contribution.mjs`**: чистые
  функции, `board-page.mjs` только рисует.

## Шаги по порядку

1. **`contribution.mjs`** (новый файл):
   - `export function periodsAt(now)` → `[{ key: "today" | "yesterday" |
     "week" | "month" | "all", title, from, to }]`, границы — ISO-строки
     UTC, посчитанные от МСК.
   - `export function contributionRows({ tasks, mergedPrs, specs, now })` →
     `{ <key>: [{ who, tasks, points, rework, reviews, specs, leadPrs }] }`.
     `specs` — `[{ id, author, addedAt }]`.
   - Разбор строки `Поток:` — регулярка с тем же форматом, что в
     `pr-check` (T-0207); `board.mjs`/`contribution.mjs` не импортируют
     `scripts/release/`, тест сверяет их на одних примерах.
2. **`git-io.mjs`.**
   - `mergedPrs()` — один запрос из «Решений», разбор в `parseMergedPrs`
     (как `parseMergedTaskPrs`: ответ не массив — `null`, поля проверяются).
     `mergedTaskPrs` остаётся для раздела «Готово» или заменяется
     фильтром по `headRefName` — на выбор, но вызов `gh` один.
   - `addedTaskSpecs(base)` → `[{ fileName, addedAt }]` по `git log`
     из «Решений».
3. **`board-page.mjs`.** `contributionSection` рисует таблицы по периодам;
   `taskCredits`/`contributions` убираются, если больше не нужны разделу
   «Готово» (столбец «Сделал» в «Готово» берёт поток из того же разбора).
4. **`task.mjs`.** `runStatusJson` собирает `contributionRows` и отдаёт
   странице.
5. **`tasks/README.md`** — там, где описан «Вклад» (если описан), или в
   абзаце о доске: какие столбцы и периоды, откуда числа.

## Чего не трогаем

- Значки статуса и разделы доски, кроме «Вклада» и столбца «Сделал» в
  «Готово».
- Доли и выплаты: «Вклад» к ним не привязан.

## Тесты

Первым коммитом, `scripts/test/tasks-contribution.test.ts` (новый) и
`tasks-board-page.test.ts`:

- `periodsAt` при `now` = 2026-10-24T21:30Z (воскресенье, 00:30 МСК
  25.10): «сегодня» — с 2026-10-24T21:00Z; «вчера» — с 2026-10-23T21:00Z
  по 2026-10-24T21:00Z; «неделя» — с понедельника 19.10 00:00 МСК, то есть
  с 2026-10-18T21:00Z; «месяц» — с 2026-09-30T21:00Z;
- задача `M`, влитая сегодня, с `Поток: claude-3 / sonnet-5.5 / medium` и
  `Запустил: владелец` → в «сегодня», «неделя», «месяц», «всё время» у
  «claude-3 · владелец» 1 задача и 2 очка; во «вчера» — нет;
- старый PR без строк, `owner` файла «claude-2 / haiku-5.5 / low» →
  «claude-2 · не указан»;
- PR с двумя коммитами «Продолжить T-0001 после ответа» → «Доработки» 2;
- комментарий `**claude-lead-1:** ответ` → «Ревью и ответы» 1 у
  «claude-lead-1 · —»; комментарий без подписи не считается;
- спецификация с `author: claude-lead-1`, добавленная вчера, → «вчера» 1;
- влитый PR ветки `lead/x` с первой строкой `**claude-lead-1:** …` → «PR
  тимлидов» 1; служебный `dev` → `main` — не считается;
- `mergedPrs` = `null` → раздел с «Нет данных GitHub», спецификации есть;
- страница: «Сегодня» и «Неделя» не в `<details>`, «Всё время» — в
  `<details>`.
