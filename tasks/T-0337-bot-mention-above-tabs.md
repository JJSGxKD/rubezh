# T-0337. Юзернейм бота — над вкладками «Заданий», после награды сворачивается в строку

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0337.json)](README.md#значки-статуса)

## Зачем

Задания «юзернейм бота в имени и в bio» продвигают игру, а игрок их не видит:
блок стоит в самом конце вкладки «Ежедневные», ниже всех заданий, а открывается
экран на вкладке «Партнёры» или там, где ждёт награда. После этой задачи блок
стоит наверху экрана, над вкладками, и виден на любой из них; получив награду за
сутки, игрок видит вместо двух карточек одну строку и не листает лишнее.

## Решения

- **Р167** (`docs/35-stage4-plan.md`, 27.10.2026): блок — вверху экрана
  «Задания», над вкладками, виден на любой вкладке. После награды за сутки
  сворачивается в одну строку «Серия N дней · завтра снова». В порядок заданий
  из панели (T-0167, T-0169) блок не входит.
- **Р110** (там же): сама механика, проверка и награда — на сервере, клиент
  показывает ответ. Не меняется.
- **Кто «свернут».** Блок сворачивается, когда награда за сутки получена у **всех
  показываемых видов** (`rewardedToday === true` у каждого из `visibleTasks`;
  если сервер отдаёт один вид — у него одного). Если награду получил один вид из
  двух, блок остаётся развёрнутым: у второго есть что делать.
- **Серия.** Сервер отдаёт серию в ответе `GET /api/v1/bot-mention`: поле
  `streak` у каждого вида (`state/bot-mention-api.ts`, `taskSchema`). Виды ведут
  серии раздельно; в строке — **наибольшая** из серий показываемых видов. Серия
  меньше 1 при полученной награде — рассогласование ответа: тогда блок не
  сворачивается, а показывается как обычно.
- **Развернуть.** Касание свёрнутой строки разворачивает блок (две карточки с
  текущим состоянием). Развёрнутый свернуть обратно можно тем же касанием по
  заголовку. Состояние «развёрнут» живёт, пока открыт экран, и не сохраняется:
  при следующем открытии блок снова свёрнут.
- **После нажатия «Проверить» блок не сворачивается сразу**, даже если награда
  только что получена: иначе сообщение «Нашли! Получено: …» исчезло бы до того,
  как игрок его прочитал. Любое нажатие кнопки в блоке разворачивает его до
  закрытия экрана; свернётся он при следующем открытии.
- **Скрытие — как сейчас:** при загрузке, ошибке, без входа
  (`tasksAvailable() === false`), при `botUsername === null` и при пустом списке
  видов блок ничего не рисует. Места под него до загрузки не резервируем (как
  решено в T-0160): вкладки сдвинутся вниз, когда блок появится.
- **Из «Ежедневных» блок убирается**, на других вкладках второй копии нет:
  блок один, над вкладками.
- Нового переключателя настроек не нужно: анимаций нет.

## Шаги по порядку

1. **Тесты — первым коммитом** (раздел «Тесты»); падают, пока кода нет.
2. **`bot-mention-rules.ts`**: добавь чистую функцию
   ```ts
   /**
    * Серия для свёрнутой строки; `null` — блок остаётся развёрнутым. Сворачиваем,
    * когда награда за сутки получена у каждого показываемого вида.
    */
   export function collapsedStreak(shown: readonly BotMentionTask[]): number | null {
     if (shown.length === 0 || !shown.every((task) => task.rewardedToday)) return null;
     const streak = Math.max(...shown.map((task) => task.streak));
     return streak >= 1 ? streak : null;
   }
   ```

## Сценарий и интерфейс

Игрок открывает «Задания» с любой вкладки. Под заголовком экрана — блок «Юзернейм
бота», затем вкладки и список. Блок один и не прыгает между вкладками.

Состояния блока:

- **Загрузка, ошибка запроса, нет входа, `botUsername === null`, пустой список
  видов** — блок не рисуется (как в T-0160); ошибка тихая, экран не ломается.
- **Не начато** — две карточки: «Юзернейм бота в имени» / «Юзернейм бота в bio»,
  кнопка «Начать», строка про самопроверку (как сейчас).
- **В процессе** — карточки со статусом (`absent`, `hidden`, `unavailable`),
  кнопка «Проверить».
- **Награда получена у одного из двух видов** — блок развёрнут, у первого нет
  кнопки и стоит «Награда за сегодня получена. Завтра проверим снова.», у
  второго — кнопка.
- **Награда за сутки получена у всех видов (при открытии экрана)** — свёрнутая
  строка на всю ширину колонки: значок бота, «Серия 5 дней · завтра снова»,
  стрелка вниз. Высота не меньше 44 px. Длинный текст обрезается многоточием, а
  не переносится.
- **Развёрнуто игроком** — заголовок «Юзернейм бота» со стрелкой вверх (касание
  сворачивает), под ним карточки.
- **После нажатия «Проверить»** — блок развёрнут, сообщение под кнопкой видно
  (в том числе «Нашли! Получено: …»); сворачивание — при следующем открытии.
- **Ограничение аккаунта** — задания бота для аккаунта обычные, отдельного
  ограничения у блока нет.

Макета нет (`design: null`): раскладка — на токенах дизайн-системы
(`bg-surface-raised`, `text-text`, `text-text-muted`, `rounded-md`), вручную
размеров и цветов вне токенов не писать.
