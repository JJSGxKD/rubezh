# T-0076. «Друзья»: крупное приглашение не мелькает, пока экран грузится

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0076.json)](README.md#значки-статуса)

## Зачем

Игрок, у которого уже есть друзья, открывает «Друзей» и на долю секунды видит
крупное приглашение «Позови друга», которое тут же уступает место подаркам и
списку. Экран дёргается. Находка приёмки PR #268 (T-0048), 13.10. После задачи,
пока сервер не ответил, крупного приглашения нет; оно появляется только у тех,
у кого друзей правда нет.

## Решения

- **До ответа сервера на экране только заголовок и строка «Загружаем друзей…»**
  (ключ `friends.loading`, уже в `i18n/ru-friends.json`). Ни крупного
  приглашения, ни подарков, ни списка. Новых текстов нет.
- **Гостю (вход не настроен) ждать нечего:** ответа не будет, поэтому у него
  крупное приглашение сразу, как сейчас (`friends.guest` рядом остаётся).
- **Сбой загрузки — тоже ответ.** При `failed` экран остаётся как сейчас:
  крупное приглашение, ошибка «Не удалось загрузить друзей — проверьте связь» и
  «Повторить». Приглашение работает и без списка (`Invite` ссылку у сервера
  спрашивает сам, `friends-parts.tsx:117`).
- **Правило порядка — чистая функция в `friends-rules.ts`**, чтобы его проверял
  тест без отрисовки: в тестовой среде приложения (`node`) компоненты не
  рисуются.

## Шаги по порядку

1. **Тесты первым коммитом** (раздел «Тесты»): заменить описание «порядок
   экрана» в `friends-rules.test.ts`. Они падают, пока кода нет.
2. **`friends-rules.ts`:** заменить `friendsLayout` (строки 40-43) на

   ```ts
   export type FriendsLoadStatus = "loading" | "failed" | "ready";
   export type FriendsLayout = "pending" | "invite-first" | "list-first";

   /**
    * Порядок экрана. Пока сервер не ответил, ни крупного приглашения, ни списка:
    * иначе у игрока с друзьями приглашение мелькнуло бы и уступило место списку.
    * Гость ответа не дождётся, а сбой загрузки — уже ответ: у обоих приглашение
    * крупное, как и у тех, у кого друзей нет.
    */
   export function friendsLayout(input: { withAccount: boolean; status: FriendsLoadStatus; friendsCount: number }): FriendsLayout {
     if (!input.withAccount) return "invite-first";
     if (input.status === "loading") return "pending";
     return input.friendsCount === 0 ? "invite-first" : "list-first";
   }
   ```

3. **`friends.tsx`, строка 78:**

   ```ts
   const layout = friendsLayout({ withAccount, status: state.status, friendsCount: view?.friends.length ?? 0 });
   ```

4. **`friends.tsx`, строка 141:** `pending` не показывает ничего.

   ```tsx
   {layout === "invite-first" ? <Invite api={api} withAccount={withAccount} variant="full" {...(bonus === undefined ? {} : { bonus })} /> : layout === "list-first" ? gifts : null}
   ```

   Ветку тела (строки 152-194) не менять: при `pending` `view` равен `null`, и
   она уже ничего не рисует.
5. **`friends.tsx`, пояснение над экраном (строки 23-25):** дописать фразу: пока
   сервер не ответил, нет ни приглашения, ни списка — только «Загружаем друзей…».
   Комментарий на русском, про «почему», без истории правок.
6. **`docs/27-design-system-and-app-shell.md`, строка «Друзья» таблицы экранов**
   (ищется по `**Друзья** | Друзья | рабочий`): в конец описания порядка экрана,
   после «…затем исходящие заявки.», добавить: «Пока сервер не ответил, экран
   показывает только «Загружаем друзей…»: крупное приглашение не мелькает у тех,
   у кого друзья есть.»

## Чего не трогаем

- `friends-parts.tsx`, `friends-api.ts`, `i18n/*`: раскладка и тексты те же.
- Окно «Спасибо за тест» и знак «Тестер» у друзей (T-0043, v0.10) правят этот
  же `friends.tsx`: там своя задача, здесь только строки из шагов 3-5.
- Повторная загрузка после действия (`act` → `load`, строка 71): состояние при
  ней остаётся `ready`, пока ответ не пришёл, поэтому ничего не мигает. Если
  перечитывание *упало*, экран падает в `failed` (список заменяется крупным
  приглашением) — это отдельное поведение, не ломаем и не чиним здесь.
- Заставка-«скелет» вместо строки «Загружаем друзей…»: нового вида загрузки нет.

## Сценарий и интерфейс

Что видит игрок со входом:

- **Загрузка** — заголовок «Друзья», плашка ограничений (если есть) и строка
  «Загружаем друзей…». Больше ничего.
- **Друзей нет** — ответ пришёл: крупное приглашение сверху, как раньше.
- **Друзья есть** — сразу подарки, заявки, «Подарить всем» и список, без
  промежуточного приглашения.
- **Ошибка** — «Не удалось загрузить друзей — проверьте связь», «Повторить»,
  крупное приглашение.
- **Нет сети** — плашка «Нет связи с сервером» сверху (T-0015) и то же, что при ошибке.
- **Без входа** — крупное приглашение и пояснение `friends.guest`.
