# T-0366. Вход в панель — опрос ответа бота только в видимой вкладке, срок — по слову сервера, а не по часам устройства

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0366.json)](README.md#значки-статуса)

## Зачем

На экране входа панель раз в 2 секунды спрашивает сервер, подтвердил ли
человек вход в боте. Есть две беды.

- **Забытые вкладки выедают общий лимит.** Лимит — 90 опросов в минуту на
  адрес (`admin-limits.ts`). Каждая вкладка входа опрашивает до получаса,
  и если в офисе за одним адресом висит несколько таких вкладок, они
  съедают лимит. Тогда человек, который входит прямо сейчас, получает
  отказ.
- **Срок истекает по часам устройства.** Панель сравнивает срок запроса с
  часами устройства. Если часы спешат, попытка «истекает» за секунды, хотя
  сервер считает её живой.

После задачи опрос идёт только в видимой вкладке, а срок решает сервер:
ответ `expired`.

## Решения

Приёмка #285 (входящие 13.10). Решения `claude-lead-1` от 01.11.2026:

- **Опрос только при видимой вкладке** (`document.visibilityState ===
  "visible"`). Вкладка скрыта — опрос стоит. При возврате во вкладку —
  сразу один опрос, затем снова раз в 2 с.
- **Срок — по серверу.** Проверку `timing.now() > expiresAtMs` из цикла
  убрать: попытку завершает ответ `expired`, его сервер уже отдаёт.
  `expiresAtMs` остаётся только для показа «осталось N мин» на экране.
- **Страховка от вечного цикла** — потолок числа опросов на попытку:
  `ceil(срок попытки / pollMs) + 5`. Ответов нет или сеть пропала —
  попытка завершается «Не дождались ответа, начните вход заново».
- В `timing` — `visible: () => boolean`, чтобы тест подменял видимость, как
  уже подменяет `now` и `wait`.

## Тесты

`apps/admin/test/session.test.ts`, с подменой `timing`:

- часы устройства на час вперёд, сервер отвечает `pending`, затем
  `confirmed` → вход состоялся;
- вкладка скрыта 10 тактов ожидания → ни одного запроса опроса;
- вкладка снова видна → опрос сразу;
- сервер вечно отвечает `pending` → попытка завершается после потолка
  опросов с текстом «Не дождались ответа».
