# T-0268. Дружина — клиент: вкладка в «Друзьях», список открытых, своя дружина с боссом недели, заявки и ссылка

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0268.json)](README.md#значки-статуса) [![T-0267](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0267.json&label=T-0267)](T-0267-clans-week-and-boss.md) [![T-0254](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0254.json&label=T-0254)](T-0254-player-card-share.md)

## Зачем

Сервер дружин (T-0266, T-0267) готов, а входа в игре нет. После задачи в
«Друзьях» есть вкладка «Дружина»:
- **без дружины** — список открытых с поиском, «Создать» и вход по ссылке;
- **в дружине** — шапка с боссом недели (полоса здоровья, мой вклад, срок),
  участники с ролями и подарками, заявки у лидера, «Позвать» ссылкой и
  «Выйти»;
- **рейтинг дружин** недели.

## Решения

Решения владельца — Р154 и поправка 24.10.2026 (вступление — по ссылке или
заявкой из списка, босс — из обычных забегов).

Решения `claude-lead-1` от 24.10.2026:

- **Вкладка «Дружина»** в «Друзьях»: вкладки «Друзья · Дружина». Две вкладки
  — прежний переключатель.
- **Без дружины:**
  - поиск по имени и список открытых (имя, участники N/20, место недели), у
    строки — «Подать заявку»;
  - кнопка «Создать дружину» — лист с именем и «Открытая / по ссылке»;
  - до 5-го уровня кнопка выключена с причиной «С 5-го уровня».
- **В дружине:**
  - **шапка** — имя, N/20, место недели;
  - **босс** — полоса здоровья (тон `danger`), «Урон дружины: X из Y», «Мой
    вклад: Z», «До конца недели: …»; победа — «Босс повержен! Награда —
    после закрытия недели»;
  - **ниже** — участники (аватар, имя, знак, роль, вклад недели; у лидера —
    «Исключить»; у всех — «Подарок», как у друзей), заявки (у лидера) и
    «Позвать в дружину» (подготовленное сообщение или ссылка);
  - **последним** — «Выйти» с подтверждением; у лидера — «лидером станет
    {имя}».
- **Вход по ссылке** — стартовый параметр с парой `clan` (T-0266) открывает
  лист «Вступить в «{имя}»?».
- **Рейтинг дружин** — список «Дружины недели» (первые 50, своя
  подсвечена).

## Сценарий и интерфейс

5-й уровень, без дружины → «Друзья» → «Дружина» → «Создать» → «Рубежники»,
открытая → своя дружина 1/20 → «Позвать» → друг по ссылке вступает → 2/20.
За неделю — полоса босса тает с каждым забегом.

Проверить 320, 390, 768, ландшафт 667×375. Состояния:
- загрузка;
- ошибка с «Повторить»;
- пустой список открытых;
- нет сети;
- ограничение аккаунта — плашка «Дружины вам недоступны».
