# T-0180. Панель «Ссылки» — автоисточники: пометка «авто», название, скрытие и сводка незнакомых меток

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0180.json)](README.md#значки-статуса) [![T-0179](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0179.json&label=T-0179)](archive/T-0179-start-param-pairs-auto-sources.md) [![T-0167](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0167.json&label=T-0167)](T-0167-admin-sortable-list-tasks-order.md)

## Зачем

После T-0179 сервер сам заводит источники по ссылкам вида `src-tgads_cmp-oct`.
Без панели маркетолог их не отличит от своих, не сможет дать понятное имя и не
уберёт мусор из списка, а незнакомые метки (ключи, которых нет в списке)
останутся в таблице, которую никто не видит. Задача — панельная половина Р116.

## Решения

**Поправка `claude-lead-1` от 21.10.2026 (приёмка #432).** После T-0179 воронка (`funnel/funnel-report.ts`) и список игроков (`player-list/player-list.repository.ts`) берут кампанию и источник только у касания `click`: у `tagged` разреза по кампании в них нет. Если в зонах этой задачи их нет — не трогать, строка во входящих; ежедневный отчёт `daily-stats` относит `tagged` к «неизвестно», как и задумано T-0179.

**Поправка `claude-lead-1` от 21.10.2026 (вопрос #432, T-0179).** Метка партнёра из ключа `prt` у источника называется **`partnerTag`** (колонка `partner_tag`): поле `partner` у `Link` и `LinkRecord` занято связью с партнёром-владельцем ссылки (T-0067). Где ниже сказано `partner` про метку автоисточника — читать `partnerTag`; новые поля `LinkRecord` после T-0179 обязательные.

Р116 (`docs/35-stage4-plan.md`): автоисточник в панели «Ссылки» помечен «авто»,
его можно **переименовать или скрыть**; незнакомые ключи копятся сводкой (ключ,
сколько раз, когда последний).

Подробности предложил `claude-lead2-1`; приняты `claude-lead-1` 19.10.2026:

- **Переименование — это `link.title`**, поле для людей; `campaign` и `source` не
  меняются: по ним идут разрезы аналитики, и переименование не должно рвать
  историю. В списке и карточке показывается `title`, а нет его — кампания.
- **Скрытие — `link.hidden_at`.** Скрытый источник не пропадает из счёта: запуски по
  нему продолжают считаться, а повторный запуск по той же метке не заводит нового
  источника и не снимает скрытие (так сделано в T-0179). Скрытие обратимо, подтверждения
  не нужно.
- **Переименовать и скрыть можно только источник с пометкой «авто»** — ссылки,
  заведённые руками, правятся как раньше (цель). Остальным запрос отвечает 400.
- Право — то же, что у всего раздела: `links.manage`. Каждое изменение — в аудит.
- Сводка незнакомых меток — **только чтение**. Ключ в код добавляется правкой
  списка (`docs/24` §3.6), а не из панели.

Решение claude-lead-1 от 19.10.2026: переименование и скрытие — только у автоисточников,
название отдельным полем `title`; кнопки «убрать из сводки» нет.

## Шаги по порядку

1. **Тесты первым коммитом** (раздел «Тесты»).
2. **Сервер, `links.repository.ts`:** `setDisplay(code, { title?: string | null,
   hidden?: boolean }, now): Promise<LinkRecord | null>` — только для `auto = true`
   (`UPDATE … WHERE code = … AND auto`), `hidden: true` → `hidden_at = now`, `false` →
   `NULL`; нет такого источника → `null`. `auto-sources.repository.ts`:
   `unknownKeys(): Promise<{ key; hits; firstAt; lastAt }[]>`, по убыванию `last_at`,
   не больше 200.
3. **`links.service.ts`:** `rename(actor, code, title)` и `setHidden(actor, code,
   hidden)` — `roles.require(actor, "links.manage")`, ссылка не авто → доменная
   ошибка валидации «Переименовать и скрыть можно только источники, заведённые
   автоматически», запись в аудит: `links.rename` (`before: { title }`, `after:
   { title }`), `links.hide` / `links.unhide`. `unknownKeys(actor)` — с проверкой
   права.
4. **`admin-links.controller.ts`:**
   - `PATCH :code/display` — тело Zod `{ title?: string | null, hidden?: boolean }`,
     хотя бы одно поле; `title` после `trim` — 1–80 знаков без управляющих, пустая
     строка или `null` сбрасывают название; ответ `{ data: LinkView }`. Маршрут
     объявить **до** `@Patch(":code")` не нужно (разные пути), но проверить порядок
     в тесте;
   - `GET unknown-keys` — **до** маршрутов `:code/...`, ответ `{ data: { keys:
     UnknownKeyRow[], limit: 200 } }`;
   - оба — `@RequirePermission("links.manage")`, изменения — под `this.limit(...)`.
5. **Панель, `api/links.ts`:** в `linkSchema` — `auto: z.boolean().catch(false)`,
   `autoKey`, `partner`, `title`, `hiddenAt` (все `nullable().catch(null)`, сервер
   старее панели не ломает список); `renameLink(api, code, title)`,
   `setLinkHidden(api, code, hidden)`, `fetchUnknownKeys(api)`; чистые функции без
   React: `linkTitle(link)` (`title ?? campaign`), `visibleLinks(rows, showHidden)`,
   `autoPairs(link)` — подписанные пары источника словами (`Источник: tgads`,
   `Кампания: oct`, `Место: post`, `Партнёр: ivan`) для карточки.
6. **`LinksScreen.tsx`:**

   - выше таблицы переключатель «Показывать скрытые (N)» — по умолчанию выключен, N
     — сколько скрыто; скрытая строка (когда показана) серая, с `Badge` «скрыта»;
   - под таблицей — блок `UnknownKeys` (шаг 8).
7. **`LinkCard.tsx`:** для автоисточника — блок «Завёлся сам»: пары через

## Сценарий и интерфейс

Маркетолог открывает «Ссылки»:

1. В таблице среди своих ссылок — строки с «авто». Он открывает карточку, видит
   «Источник: tgads, Кампания: oct», нажимает «Переименовать», вводит «Посев в
   Канале N» — в списке теперь это название.
2. Мусорный источник скрывает кнопкой «Скрыть»; он уходит из списка, в «Показывать
   скрытые (1)» — виден серым с «Вернуть в список».
3. Ниже таблицы — «Незнакомые метки»: `utm — 14 раз, вчера в 21:40`. Он понимает,
   что кто-то ставит чужие метки, и передаёт команде добавить ключ.

Состояния: загрузка списка и сводки — `Loading`; нет автоисточников — блок «Завёлся
сам» просто не показан; ошибка сохранения названия — `ErrorNotice` в диалоге, поле
не сбрасывается; нет сети — общая плашка панели; слишком частые изменения — 429 с
текстом сервера. Проверить вручную в браузере на 320 и 1440 px: таблица и диалог не
дают горизонтальной прокрутки страницы (снимков экранов в панели нет).
