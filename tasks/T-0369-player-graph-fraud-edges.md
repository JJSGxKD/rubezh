# T-0369. Граф связей — связи антифрода по отдельному праву; признаки — у владельца

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0369.json)](README.md#значки-статуса) [![T-0367](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0367.json&label=T-0367)](T-0367-player-graph-server.md)

## Зачем

Ферму аккаунтов видно не по дружбе, а по общим признакам, которые собирает
антифрод. После задачи у графа связей (T-0367) есть ещё один вид связи — по
признакам антифрода. Его видят только роли с отдельным правом.

## Решения

Решение владельца — Р182: связи антифрода — только ролям с доступом;
**признаки в публичный код и описание задачи не выписываются** — это
локальный аудит. Поэтому задача — владельца (`runner: owner`): здесь
описано только то, что можно держать в открытом репозитории.

Решения `claude-lead-1` от 01.11.2026:

- **Право** `players.fraud.view` — новое, в каталоге прав и у роли
  владельца по умолчанию. Название для панели — «Связи антифрода».
- **Вид связи** — `signal`, подпись для панели — «общий признак», без
  названия признака. Сервис графа отдаёт такие связи только при праве;
  без права их нет в ответе, а не просто скрыто в панели.
- **Источник** — подключается к сервису графа списком источников, как
  предусмотрела T-0367. Где и как он берёт признаки — решает владелец
  локально.
- **Потолок узлов** общий с остальными связями (200).

## Шаги по порядку

1. Тест первым коммитом: без права связей `signal` в ответе нет; с правом —
   есть, если источник их вернул (источник в тесте — заглушка).
2. Право в каталоге и у роли владельца.
3. Источник связей и подключение к сервису графа.

## Чего не трогаем

(T-0368).
