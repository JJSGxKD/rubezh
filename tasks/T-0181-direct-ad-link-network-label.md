# T-0181. Прямая ссылка на Mini App для рекламы AdsGram — метка кампании сети в стартовом параметре и конверсия по запуску

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0181.json)](README.md#значки-статуса) [![T-0179](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0179.json&label=T-0179)](T-0179-start-param-pairs-auto-sources.md)

**Статус `draft`: ждёт ответа пользователя на вопросы ниже.** Без них формат
параметра выдуман, а реклама на нём не заработает.

## Зачем

Модерация AdsGram плохо принимает переходники, и каждое объявление приходится
согласовывать через менеджеров (Р117). Нужна прямая ссылка на Mini App
(`t.me/<бот>?startapp=…`), в которой едут код ссылки и метка клика сети, а
запуск по ней засчитывается ссылке и уходит сети конверсией — так же, как через
переходник. Переходник `/r/<код>` остаётся для всех остальных мест.

## Решения

Р117 (`docs/35-stage4-plan.md`, 19.10.2026): для рекламы — прямая ссылка на Mini
App; нужные данные, включая код ссылки и метку клика сети, едут в стартовом
параметре; переходник остаётся; у прямой ссылки сервер не видит клика, только
запуск — клики дают кабинеты сетей.

**Открытые вопросы пользователю (без ответа задача не `ready`):**

1. **Формат метки сети.** В репозитории и `docs/24` §3.5 известны только макросы
   AdsGram для веб-ссылки через переходник: `{campaign_id}`, `{banner_id}`,
   `{publisher_id}`, `{click_id}`, `{record_data}` (`link-networks.ts`); для ссылок
   «внутри Telegram» в коде упомянут только `{campaign_id}` (`conversion-rules.ts:69`).
   **Подставляет ли AdsGram макрос внутрь значения `startapp` у ссылки на Mini App и
   какие макросы там доступны?** Нужен образец адреса из кабинета или документации
   AdsGram «Трекинг конверсий».
2. **Каким постбэком уходит конверсия**, если `{record_data}` у такой ссылки нет:
   вариантом для Telegram-ссылок (`tgid` + `campaignid`, он уже есть в
   `adsgramPostbackUrl`) — это подходит?
3. **Вид параметра.** Предложение `claude-lead2-1`: `l-<код>_<campaign_id>`, то есть
   прежний `l-<код>` и через `_` числовая метка кампании (всё в 64 знака,
   `A-Za-z0-9_-`). `{campaign_id}` пишется в адрес **без кодирования**, как
   макросы переходника (`links.service.ts:165`), иначе сеть его не найдёт.

## Как сейчас

- Прямая ссылка: `links/link-targets.ts:68-72` — `directUrl` **возвращает `null`
  для ссылки с сетью** (`link.network !== null`), на карточке — строка «Ссылка
  закупки — только через переходник» (`apps/admin/src/api/links.ts:28`). Сети нужны
  макросы, а их раньше писал только переходник.
- Параметр `l-<код>`: `attribution/start-param.ts:77-81`, вид `link`, `ref` — код
  ссылки; запуск — касание, как у клика. После T-0179 в файле добавлен разбор
  `ключ-значение`, и новая форма `l-<код>_<метка>` обязана разбираться раньше его.
- Построитель адреса Mini App: `platforms/telegram/telegram-app-links.ts:20` —
  `encodeURIComponent(startParam)`; фигурные скобки он закодирует.
- Конверсии: `ad-conversions/conversions.repository.ts` `sweep` (строки 97-150)
  выбирает кандидатов только по `first_start_kind = 'click'` и `link_click`;
  `due` (строка 160) берёт макросы из `link_click.network_params`.
  `ad_conversion.click_id` — `NOT NULL` с внешним ключом на `link_click`
  (`schema.prisma:2128,2146`), уникальность — `(click_id, goal)` для целей 1 и 2
  (`migrations/20261002180000_ad_conversions`).
- Постбэк: `conversion-rules.ts:67-92` `adsgramPostbackUrl` — вариант `record`, а
  при только `campaign` и Telegram ID — `tgid` + `campaignid`.
- Итог проверки: **сейчас у запуска по прямой ссылке нет ни метки, ни
  конверсии** — это и есть разрыв, который закрывает задача.

## Шаги по порядку

(Предварительно, после ответов на вопросы. Формат метки — из ответа на вопрос 1.)

1. **Тесты первым коммитом** (раздел «Тесты»).
2. **Параметр:** `start-param.ts` — `l-<код>` и `l-<код>_<метка>`; метка — `[0-9]{1,20}`
   (если ответ на вопрос 1 другой — по нему). Код проверяется прежним `LINK_CODE`.
   Результат — вид `link`, `ref` — код, метка сохраняется в сырой `startParam`
   сессии (она уже там) и выделяется функцией `networkLabelOf(startParam)`.
3. **Адрес:** `link-targets.ts` `directUrl` для ссылки с сетью собирает
   `launch("l-<код>_<макрос>")` с макросом сети из профиля (`link-networks.ts`,
   новое поле профиля `directMacro: "{campaign_id}"`). Порт `AppLinks` /
   `telegram-app-links.ts` получает способ собрать адрес **без кодирования
   макроса** (отдельный аргумент: часть, которую кодировать нельзя). У ссылки сети
   по-прежнему два адреса: `networkUrl` (переходник, с макросами) и `directUrl`.
4. **Миграция** (только добавления; по процедуре «Общие файлы»):
   `ad_conversion.click_id` становится nullable; новый частичный уникальный индекс
   `(account_id, goal) WHERE click_id IS NULL AND goal IN (1, 2)` — повторная
   отправка не дублирует конверсию; у записи — `start_label` (`VarChar(32)`,
   метка кампании сети).
5. **`sweep`:** вторая ветка кандидатов — `first_start_kind = 'link'`, ссылка с сетью,
   новичок (`account.created_at >= first_at - 1 минута`), окна и условия регистрации
   и покупок те же, что у клика, отсчёт — от `acquisition.first_at`. Метка берётся из
   `acquisition.first_start_param`. Аккаунты команды — пропущенными, как у клика.
6. **`due` / отправка:** запись без клика берёт метку из `start_label` и Telegram ID
   игрока, постбэк — вариант `tgid` + `campaignid`. Нет метки — «нет меток», как
   сейчас.
7. **Панель:** на карточке ссылки сети — второй адрес «Прямая ссылка для рекламы» с
   кнопкой «Скопировать» и подсказкой, чем она отличается от переходника: сервер не
   видит клика, считает запуски; вместо строки «Ссылка закупки — только через
   переходник». Счёт «через переходник» и «прямых» уже раздельный.
8. **Документы:** `docs/24` §3.4 (прямая ссылка есть и у ссылки сети), §3.5 (откуда
   метка, какой постбэк), §5 (вид `l-<код>_<метка>`); `docs/21` — поток и ER.

## Чего не трогаем

- Переходник `/r/<код>`, его страницу, клики и макросы на клике: путь через
  переходник работает как раньше.
- Автоисточники по ключам (T-0179) и панель к ним (T-0180).
- Токен конверсий, журнал и повторы отправки.
- Другие сети: профиль сети по-прежнему один — AdsGram.
