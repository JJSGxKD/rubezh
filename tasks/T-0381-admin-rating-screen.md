# T-0381. Рейтинг в панели — раздел: доски, архив сезонов, места игрока в карточке

## Зачем

После T-0380 у сервера есть ручки рейтинга, а в панели их не видно. После
задачи в меню есть раздел «Рейтинг»: доски по сложностям сейчас, архив
недельных сезонов с местами, дивизионами и наградами; а в карточке игрока —
его места по неделям, со ссылками туда и обратно.

## Решения

Записаны в `docs/35-stage4-plan.md` Р189 и в T-0380 (решения 3–5). Исполнитель
их не пересматривает.

1. **Раздел «Рейтинг»**: текущие доски по сложностям, архив недельных сезонов с
   местами, дивизионами и наградами, места игрока по неделям — по уже
   записанным итогам (Р189).
2. **Право — `players.view`** (T-0380, решение 4). Раздел — в группе меню
   «Вовлечение» (`routes.ts`: «чем возвращаем»), после «Заданий».
3. **Отдельная доска** — переключатель «Доска: общая / полная» и колонка «Доска»
   в местах игрока — только при праве `players.board.restrict` (T-0380,
   решение 5). Без права их нет вовсе, а не выключены.
4. **Связь с карточкой игрока**: имя в любой таблице раздела — ссылка
   `#/players/<accountId>/runs`; в карточке игрока на вкладке «Забеги» — панель
   «Места по неделям», где неделя — ссылка `#/rating/<ключ сезона>/<сложность>`.

## Сценарий и интерфейс

- **Открыл «Рейтинг»** → «Доски сейчас» на неделе и сложности «Сложная»
  (`hard` — сложность игрока, Р126), ниже архив.
- **Нажал имя** → карточка игрока, вкладка «Забеги», в ней «Места по неделям».
- **Нажал неделю** в архиве или в карточке → итоги сезона на этой сложности.
- **Загрузка** — `Loading` в каждой панели отдельно; **ошибка** — `ErrorNotice`
  с «Повторить» в своей панели, соседняя работает.
- **Пусто:** сезона нет — «Сезон не идёт — доска недели появится с его началом»;
  доска пуста — «На этой доске пока никого»; архив пуст — «Закрытых сезонов
  ещё нет»; у игрока мест нет — «Игрок не попадал в итоги недельных сезонов».
- **Нет права `players.view`** — раздела нет в меню, адрес ведёт на
  «нет доступа», как у остальных разделов.

Снимки в PR: доски, сезон и панель в карточке — на 390 и 1440 px; на 390 таблицы
в телефонной раскладке `DataTable`, без боковой прокрутки страницы.

## Тесты

Первым коммитом, `apps/admin/test/rating.test.ts`:

- схемы: ответ T-0380 разбирается; лишнее поле не роняет, отсутствующее
  обязательное — ошибка;
- запросы: `fetchRatingBoards` шлёт `GET /api/v1/admin/rating/boards?difficulty=hard&period=week&board=common&limit=100`;
  `fetchSeason` — `/rating/seasons/2026-11-02?difficulty=hard&board=common&offset=0&limit=100`;
  `fetchPlayerSeasons` — `/players/<id>/seasons`;
- `scoreText`: 754 секунды по времени → «12:34»; 1830 очков → «1 830 оч.»;
- `weekTitle("2026-11-02")` → «2–8 ноября 2026»; неделя через границу месяца
  `2026-11-30` → «30 ноября – 6 декабря 2026»;
- маршрут: `parseRoute("#/rating/2026-11-02/hard")` → раздел `rating`, id
  ключа, вкладка `hard`; раздел «Рейтинг» есть в группе «Вовлечение» с правом
  `players.view`;
- пояснения `HELP.rating.*` и `HELP.players.seasonPlaces` есть и не обращаются
  на «ты» (как `help.test.ts`).
