# T-0479. Итог забега — типы врагов, вышедших в мир (enemiesSeen), для кодекса

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0479.json)](README.md#значки-статуса)

## Зачем

Кодекс врагов (T-0127, PR #686) открывает запись, когда игрок **встретил**
врага. Сервер узнаёт о встречах из итога забега, но там есть только
`topKills` — восемь самых частых убитых. Босс и элита в них почти никогда не
попадают, и кодекс достижим максимум на 8 из 11 врагов: «Полный кодекс»
(`ach_codex_100`) недостижим. Задача добавляет в итог забега список типов
врагов, которые вышли в мир, — поле `stats.enemiesSeen`, обещанное T-0125.

## Решения

- Решение тимлида claude-lead-1 13.11.2026 по ревью #686: вариант (a) —
  поле отдельной задачей, T-0127 вливается после неё (#686 — «задел»).
- «Встретил» — **враг этого типа появился в мире забега** (заспавнился,
  включая боссов, элит, стражей кольца и потомков делящихся), а не «убил».
- Только id из контента; порядок — первого появления; без повторов. Длина
  ограничена числом врагов в контенте (сервер — `max(64)`).
- Детерминизм: сбор — по событию появления в симуляции, без случайности и
  времени; golden-эталоны **не меняются** (поле в итоге, не в мире).

## Как сейчас

- Итог — `packages/core-game/src/game/run/run-result.ts`: `killsByEnemy(world)`
  (строка ~90); тип — `RunResult` в `packages/shared-types/src/index.ts`
  (строка ~1804).
- Клиент — `packages/app-shell/src/state/runs.ts`, строка ~319:
  `topKills: Object.entries(result.killsByEnemy)…`.
- Сервер — `backend/api/src/modules/runs/dto/runs.dto.ts`, строка ~111:
  `topKills: z.array(…).max(8)` в `runFinishSchema`.

## Шаги по порядку

1. Симуляция: множество id появившихся типов в состоянии мира (там, где
   ведётся статистика забега), пополняется в точке спавна врага любого
   ранга; снимок прерванного забега его хранит (иначе после продолжения
   список неполный).
2. `run-result.ts`: `enemiesSeen: string[]` — в порядке первого появления.
3. `shared-types`: поле в `RunResult` (необязательное для старых итогов).
4. Клиент `runs.ts`: `stats.enemiesSeen` в отправке итога.
5. Сервер `runs.dto.ts`: `enemiesSeen: z.array(enemyId).max(64).optional()`
   в `stats`; нет поля (старый клиент) — как раньше.
6. `docs/22-analytics-and-metrics.md` — если поля итога забега там
   перечислены, строка про `enemiesSeen`.

## Чего не трогаем

- Кодекс и его награды — PR #686 (T-0127) после этой задачи.
- `topKills` и `killsByEnemy` — как есть.

## Сценарий и интерфейс

- Забег до 9-й минуты с боссом: `enemiesSeen` содержит рядовых, элиту и
  босса в порядке появления, даже если босса не убили.
