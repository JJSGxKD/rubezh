# T-0295. Дивизионы сезона по доле доски и стиль игрока — сильнейшая ось лучшего забега, «Твой стиль» с подсказкой, что поднимет слабую ось

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0295.json)](README.md#значки-статуса) [![T-0294](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0294.json&label=T-0294)](T-0294-rating-boards-by-points.md)

## Зачем

Рейтинг по очкам (T-0294) честный, но для игрока это список чисел.

- **Дивизион** даёт ступень: «я в золоте».
- **Стиль** даёт лицо: «я — Тень».
- **«Твой стиль»** даёт цель: какая ось слабая и что её поднимет.

После задачи сервер отдаёт всё это экранам рейтинга и сезона (T-0296).

## Решения

Решения владельца — `docs/35-stage4-plan.md`:
- Р152:
  - сильнейшая ось лучшего забега — **стиль у имени** (Стена, Ураган, Охотник, Тень, Мастер);
  - дивизионы — по доле сезона;
- `design/art/meta-v2.md` §2.3–2.4: «Твой стиль» в «Сезоне»; рубин — топ-1 %,
  золото — 10 %, серебро — 35 %, бронза — все с забегом.

Решения `claude-lead-1` от 25.10.2026:

- **Дивизион** — по месту в сезонной доске и её размеру, при чтении:
  - `ruby` — место ≤ `ceil(0,01 × размер)`;
  - `gold` — ≤ `ceil(0,10 × размер)`;
  - `silver` — ≤ `ceil(0,35 × размер)`;
  - `bronze` — остальные с рейтинговым забегом сезона;
  - нет забега — без дивизиона.

  Рубин всегда есть хотя бы у первого. Скрытая доска — дивизион по своей
  доске.
- **Сохранение** — при закрытии сезона дивизион пишется в `season_result.division`.
  Награды сезона дивизион не меняет (лестница мест прежняя, T-0294); знак
  дивизиона — не в этой задаче: знаки у имени — отобранный список Р149.
- **Стиль игрока** — `style` лучшего по очкам забега текущего сезона:
  - нет сезонного — лучшего за всё время;
  - нет забегов с очками — без стиля.

  Приходит в строках досок и в публичном облике игрока: поле `style` у
  `PublicIdentity` (T-0240) — в рейтинге, друзьях, карточке.
- **«Твой стиль»** — `GET /api/v1/rating/me/style`:
  - среднее индексов осей (с потолком 3) по последним 10 рейтинговым
    забегам;
  - сильная ось — наибольшее среднее, слабая — наименьшее;
  - меньше 3 забегов — `null` и «Сыграй ещё {n}, чтобы узнать свой стиль».

  Ответ: `{ style, strong, weak, axes: { t, k, h, c, b }, runs }`.
- **Подсказка к слабой оси** — ключ `rating.hint.<ось>` в `ru.json`, текст в
  T-0296. Сервер отдаёт только ось.
