# T-0187. Строки свойств предмета — значение не переносится, прибавка видна и при малом шаге

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0187.json)](../README.md#значки-статуса)

## Зачем

В листе предмета на телефоне строка «Восстановление в секунду +0,2 → +0,2»
разваливается: стрелка остаётся на первой строке, новое значение уезжает на
вторую, а сама прибавка не видна — до и после стоит одно и то же «+0,2», хотя
улучшение её меняет. После задачи значение строки целиком в одну строку справа,
переносится только название, а у малой прибавки появляется лишний знак после
запятой, чтобы разница читалась. Источник — скриншот участника 1, 20.10.2026
(лист сапог, 390 px).

## Решения

Р124 (`docs/35-stage4-plan.md`, 20.10.2026):

- **значение строки не переносится**: «было → стало» — одним куском справа, не
  сжимается; переносится название свойства (и значок «?» остаётся за последним
  словом названия, как сейчас);
- **прибавка видна всегда**: если на одном знаке после запятой «было» и «стало»
  выглядят одинаково, оба показываются с точностью до двух знаков (нули в конце
  `formatDecimal` по-прежнему не печатает); если одинаковы и с двумя
  — строка показывает одно значение без стрелки, как свойство, которое не
  меняется;
- правило — чистой функцией рядом со `statValue`, остальные места, где
  показывается свойство (`arsenal.tsx`, `run-detail.tsx`, `shop-showcase.tsx`),
  не меняются: там нет пары «было → стало».

  - значение — `span` с `flex min-w-0 flex-wrap` (строка 137): при нехватке места
    «→» и новое значение уезжают на следующую строку;
  - с подсказкой значение уходит в слот `end` компонента `Hint`
    (`design-system/components/Hint.tsx:23-38`: название `min-w-0`, `end` — сосед
    справа), без подсказки — `flex justify-between` (строка 159).

## Шаги по порядку

1. **Тест первым коммитом** (раздел «Тесты»).
2. **`arsenal-parts.tsx`** — рядом со `statValue`:

   ```ts
   /**
    * «Было → стало» для строки свойства. На одном знаке после запятой малая
    * прибавка не видна — тогда оба значения до двух знаков; не видна и так —
    * `to: null`, строка показывает одно значение.
    */
   export function statChange(stat: string, from: number, to: number): { from: string; to: string | null }
   ```

   Знаки — через тот же `formatDecimal` и то же деление на число и проценты, что
   у `statValue` (`statValue` получает необязательный третий аргумент
   `digits = 1`, по умолчанию поведение прежнее).
3. **`arsenal-item.tsx` `StatRow`:**
   - при `nextValue !== undefined` строку строит `statChange`; `to === null` — как
     ветка без изменения (одно значение, `text-success`);
   - обёртка значения: убрать `flex-wrap` и `min-w-0`, добавить `shrink-0
     whitespace-nowrap` (стрелка и оба значения в одну строку);
   - название в ветке без подсказки — `min-w-0` (переносится оно, а не значение).

## Сценарий и интерфейс

Игрок открывает лист надетого предмета, у которого есть улучшение:

- прибавка заметна на одном знаке («+3,8% → +4%») — как сейчас, но в одну строку;
- малая прибавка («+0,2 → +0,2» сейчас) — «+0,2 → +0,24»;
- улучшение свойство не меняет — одно значение без стрелки;
- предмет максимального уровня (`next` нет) — одно значение, как сейчас;
- режим перекрутки (строки — кнопки) — та же строка, без подсказки.

На 320 px длинное название («Восстановление в секунду», «Сопротивление холоду»)
переносится на две строки, значение справа целиком.

## Тесты

`packages/app-shell/test/arsenal-stat-change.test.ts` (чистые, вызывает
`statChange`):

- `regenPerSec`, 0,2 → 0,24 → `{ from: "+0,2", to: "+0,24" }` (на одном знаке
  оба «+0,2», на двух — разные);
- `regenPerSec`, 0,2 → 0,5 → `{ from: "+0,2", to: "+0,5" }` (одного знака хватает);
- `moveSpeed`, 0,038 → 0,04 → `{ from: "+3,8%", to: "+4%" }` — так, как сегодня
  печатает `formatDecimal` (`maximumFractionDigits`: нулей в конце нет);
- `resistCold`, 0,039 → 0,0392 → `{ from: "+3,9%", to: "+3,92%" }`;
- `armor`, 2 → 2,001 → `to: null` (не видно и на двух знаках);
- `statValue` без третьего аргумента печатает как раньше (регрессия на два
  свойства — число и процент).

Снимки листа предмета в описании PR: 320, 390, 768 px, предмет с длинными
названиями свойств и малой прибавкой.
