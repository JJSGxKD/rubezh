# T-0094. Лист «Перед забегом»: отмеченная плитка справа не даёт боковой прокрутки

[![статус](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/JJSGxKD/rubezh/task-board/status/T-0094.json)](../README.md#значки-статуса)

## Зачем

Игрок отмечает оружие или буст в правой колонке листа «Перед забегом», и у
тела листа появляется горизонтальная полоса прокрутки: значок-галочка в углу
плитки торчит за правый край сетки. Лист начинает ездить вбок. После задачи
лист вбок не прокручивается никогда, а галочка не выходит за границы плитки.
Замечание с живого теста, 13.10.

## Решения

- **Решение участника 1 от 13.10.2026 (тест):** лист никогда не прокручивается
  вбок; значок выбора не выходит за границы сетки; вертикальная прокрутка
  остаётся как есть.
- **Значок переезжает внутрь плитки**, в её правый верхний угол «уголком» (по
  контуру плитки, цвет акцента — как у кольца выбора). Это лечит причину, а не
  симптом: плитка с таким значком безопасна в любой прокручиваемой оболочке.
- **Страховка на теле листа:** `overflow-x-hidden` плюс боковой запас в 4 px
  (`-mx-1 px-1`), чтобы кольцо выбранной плитки в крайней колонке не срезалось
  краем прокрутки (сейчас срезается на 2 px с внешней стороны).
- **Правило «нет выноса за границу» — чистая функция** `hasOutsideOffset` в
  `pick-tile-rules.ts`: DOM-тестов у оболочки нет (среда `node`), поэтому
  проверяется строка классов значка.

## Как сейчас

- `packages/app-shell/src/screens/pick-tile.tsx:72-76` — значок выбора:

  ```tsx
  <span aria-hidden="true" className="absolute -top-1.5 -right-1.5 inline-flex size-4 items-center justify-center rounded-sm bg-accent text-on-accent">
    <Check size={11} strokeWidth={3.5} />
  </span>
  ```

  `-right-1.5` выносит его на 6 px за правый край плитки. Плитка (`:49`) —
  `relative … rounded-lg p-2` (`max-[359px]:p-1.5`), у выбранной кольцо
  `ring-2 ring-accent` с мягким свечением (`:53`).
- `packages/app-shell/src/screens/pre-run.tsx:171` — тело листа:
  `<div className="grid max-h-[max(10rem,calc(100dvh-20rem-var(--app-inset-top)-var(--app-inset-bottom)))] grid-cols-1 gap-1.5 overflow-y-auto overscroll-contain">`.
  Без `overflow-x` браузер считает его `auto` (как только `overflow-y` не
  `visible`), а своих боковых отступов у тела нет.
- Плитки оружия — `pre-run.tsx:230-235` (`grid grid-cols-3`), бустов —
  `boost-picker.tsx:67,83` (тот же `PickTile`, правится только он).
- **Причина.** Плитка третьей колонки кончается ровно на правом краю тела;
  значок торчит ещё на 6 px вправо — это прокручиваемое переполнение, и
  появляется горизонтальная полоса. Вынос влево и вверх полосы не даёт (туда
  нельзя прокрутить), его просто срезает край.
- Тело `Modal` (`design-system/components/Surfaces.tsx:178`) — отдельный блок с
  `px-5` (`short:px-4 landscape:px-4`); запас в 4 px укладывается в его поля.

## Шаги по порядку

2. **Новый файл `packages/app-shell/src/screens/pick-tile-rules.ts`:**

   ```ts
   /**
    * Значок выбора лежит внутри плитки, в её правом верхнем углу, и повторяет
    * контур плитки (`rounded-lg`): всё, что выходит за правый край
    * прокручиваемого листа, даёт ему горизонтальную полосу. Высота 14 px — чтобы
    * на 320 px уголок не наезжал на цену буста в первой строке плитки.
    */
   export const SELECTED_MARK_CLASS =
     "absolute top-0 right-0 inline-flex size-3.5 items-center justify-center rounded-tr-lg rounded-bl-md bg-accent text-on-accent";

   const OUTSIDE_OFFSET = /^-(?:top|right|bottom|left|start|end|inset(?:-[xy])?)-/;
   const OUTSIDE_TRANSLATE = /^-translate-[xy]-/;

   /** Выносит ли набор классов элемент за границу родителя: `-top-1.5`, `-right-1`, `-inset-x-1`, `-translate-x-1/2`. Отрицательные отступы (`-mx-1`) не в счёт. */
   export function hasOutsideOffset(classes: string): boolean {
     return classes
       .split(/\s+/)
       .map((token) => token.slice(token.lastIndexOf(":") + 1))
       .some((token) => OUTSIDE_OFFSET.test(token) || OUTSIDE_TRANSLATE.test(token));
   }
   ```

## Сценарий и интерфейс

Что видит игрок на 320, 360, 390 px и в ландшафте:

- **Плитка не выбрана** — как раньше, значка нет.
- **Выбрана плитка слева, в середине или справа** — в правом верхнем углу
  плитки заливка акцентом в форме уголка с галочкой; кольцо видно со всех сторон,
  в том числе у крайней колонки.
- **Выбран буст с ценой** — уголок над ценой, не перекрывая её, на любой
  ширине.
- **Лист листается только вверх-вниз**, боковой полосы нет ни при выборе, ни
  без него.
- Загрузки, пустого состояния, ошибки и «нет сети» у правки нет: меняется
  только отметка выбора.

## Тесты

Первым коммитом. Новый `packages/app-shell/test/pick-tile-rules.test.ts`
(`describe("значок выбора плитки", …)`), импорт из
`../src/screens/pick-tile-rules`:

- `hasOutsideOffset("absolute -top-1.5 -right-1.5 inline-flex size-4")` →
  `true` (прежний значок);
- для каждого из `-top-2`, `-right-1`, `-bottom-1`, `-left-1`, `-start-1`,
  `-end-1`, `-inset-1`, `-inset-x-1`, `-inset-y-1`, `-translate-x-1/2`,
  `-translate-y-1` → `true`;
- с вариантами: `max-[359px]:-right-1` и `landscape:-top-1` → `true`;
- `absolute top-0 right-0` и `inset-0 top-1 right-1` → `false`;
- отрицательные отступы не считаются выносом: `-mx-1 -mt-1 px-1` → `false`;
- пустая строка → `false`;
- `SELECTED_MARK_CLASS`: `hasOutsideOffset(SELECTED_MARK_CLASS)` → `false`, а
  набор классов (`split(" ")`) содержит `absolute`, `top-0` и `right-0`.
