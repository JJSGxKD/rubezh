# Bullet-heaven / dungeon-runner мини-игра — проектная документация

Кроссплатформенная HTML5-игра в жанре bullet heaven / arcade dungeon-runner
(автоатака при остановке персонажа + перемещение по небольшим локациям,
прогрессия за забег, roguelite-апгрейды) для MAX, Telegram и VK.

## Ключевые решения (коротко)

- **Платформы**: MAX (первая цель, наименьшая конкуренция) → Telegram (порт) → VK (опционально, есть нативная реклама)
- **Движок**: Phaser 3 + Vite, весь игровой цикл платформонезависим
- **Бэкенд**: NestJS + PostgreSQL + Prisma + Redis (переиспользование текущего стека)
- **Монетизация**: только прямые IAP фиксированной стоимости (без рандома/лутбоксов) — скины, континью, сезонный контент
- **Архитектура**: `core-game` (общее) + `adapter-{telegram,max,vk}` (тонкий платформенный слой) + общий бэкенд
- **Команда**: 3 человека — техническая реализация (движок, бэкенд, платформенные адаптеры), геймдизайн/баланс/экономика (выделенная роль, профильное образование и опыт) и техническая адаптация ассетов/монетизация/QA (Unity/Gmod/Яндекс Игры опыт). Контент вынесен в данные специально под такое разделение, см. `01-tech-stack.md` §9 и `06-team-and-workflow.md`
- **Фазирование**: MVP (6-8 недель, `02-roadmap.md`) — один режим забега, простая мета-валюта, лидерборд на MAX. Веб-версия, снаряжение с редкостью, рейтинговая лига, уровень аккаунта — сознательно вынесены в Фазу 2 (`10-progression-and-ladder.md`, `08-web-and-identity.md`), не блокируют публичный лонч
- **Юрлицо и деньги**: вся регистрация (ИП/самозанятость), налоги, договоры с партнёрами — на участнике 1. Доход делится ежемесячно после расходов/налога/погашения займа: 45% / 27.5% / 27.5%, формулы — `11-revenue-split.md`. Доля действует, только пока участник ведёт проект — правило жёсткое, без частичного вестинга
- **IP**: репозиторий публичный под source-available лицензией (не MIT/Apache) — посторонним нельзя монетизировать, участникам разработки можно переиспользовать код под другим брендом. Антифрод-логика и бэкенд — отдельно, не публикуются. Детали — `12-ip-and-licensing.md`
